# Электро-стол

Детская браузерная игра (для 5+ лет, планшет/телефон): собирай простые электрические схемы
из батарейки, лампочки, вентилятора, выключателя, светодиода и пищалки и смотри, что получится.

```bash
npm install
npm run dev      # открыть на планшете по адресу из консоли (та же Wi-Fi сеть)
npm test
npm run build
```

Подробности об устройстве проекта и правила работы — в [AGENTS.md](AGENTS.md).
