# Ферма v3 — композиция до реализации

Предложение по m0109/m0113. Актуальный образ — **concept-v3-dense.png**, с учётом присланных владельцем референсов мобильных ферм: яркая трава, крупный амбар, цветные прямоугольники культур, группы животных, плотный лесной край, короткие связи между дворами. Размер предложения **110×75**. `concepts.html` собирает материалы для ревью.

Это концепт, а не скриншот готовой игры. На этом шаге код игры и существующие GLB не менялись, Tripo для фермы v3 не использовалась. Копию личного скриншота владельца в публичный репозиторий не добавляли.

## Что считать точным

- `layout-proposal.json`: 17 заданий, предложения центров 4×4 площадок и столбов; x вправо, z вниз/на юг. Границы x ±55, z ±37.5. У коровы две отдельные площадки, поэтому 17 задач соответствуют 16 персонажам/группам.
- `layout-technical.svg`: строго верхняя инженерная схема из этих данных. Ровно 10×10 одинаковых клеток, каждая 11×7.5. Это схема координат, **не нарисованные кодом игровые ассеты**. Воспроизводится `python3 assets-src/farm-v3/build-layout.py`.
- Проверено: все 17 площадок не пересекаются, расстояния до столбов 4–6. Для уток и козлят предложен общий столб (-20,5), на расстоянии 5 от обоих.
- Это пока предложение координат, не готовые значения для импорта в игру. Дороги, разрывы заборов, свободные зоны вокруг деталей, достижимость животного и механизмов требуют проверки при реализации. Художественная картинка не задаёт точные габариты.

## Ограничения Image-плана

`plan-v2.png` передаёт ту же общую раскладку, но сохранил небольшой наклон, изменил некоторые крыши/цвета и сделал нижний ряд сетки ниже остальных. Не снимать из него численные координаты. Для этого приложена точная SVG-схема и JSON. `concept-v1`, `concept-v2-access`, `plan-v1-superseded` — предыдущие итерации, не актуальный план.

В concept-v3 котёнок нарисован в высоком проёме амбара. В игре его нужно поставить на **низкую боковую площадку сеновала**, до которой достаёт реальный лифт; верхний проём на картинке не является техническим требованием. Пропорции амбара и его главного окна не должны вынуждать менять высоту лифта. Карусель, вентиляторы, насосы, фонтан, ворота, провода остаются функциональными частями игры; их работа важнее декоративного совпадения с картинкой.

## Переиспользовать имеющееся

Уже есть `barn`, `coop`, `stable`, `doghouse`, `hutch`, `haystack`, `beehive`, `tree-oak`, `tree-pine`, `bush`, `rock-cluster`, `flower-cluster`, обе `flowerbed`, `fence`, `fence-post`, `tractor` и все животные фермы, включая `fox-rig`. Конюшню, стог, ёлки и камни повторно не заказывать. Калитку сначала попробовать получить из имеющейся секции забора с отдельным шарниром. Возле кроликов использовать hutch, а не вторую будку для собаки.

После одобрения состава: вероятно нужны фермерский дом, силос, свинарник, навес, телега/тачка, колодец, пугало, мостки, ящик/бочка, рулон сена и модульные ряды культур. Сперва подтвердить, что нельзя собрать вариант из существующего без потери качества. Ряды культур делать небольшими повторяемыми GLB и инстансить, не моделировать тысячи отдельных стеблей. Детали/площадка/ворота никогда не перекрываются растительностью. Список не является заказом генераций.
