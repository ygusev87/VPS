# Ферма v3 — композиция до реализации

Предложение по m0109/m0113. Актуальный образ — **concept-v3-dense.png**, с учётом присланных владельцем референсов мобильных ферм: яркая трава, крупный амбар, цветные прямоугольники культур, группы животных, плотный лесной край, короткие связи между дворами. Размер предложения **110×75**. `concepts.html` собирает материалы для ревью.

Это концепт, а не скриншот готовой игры. На этом шаге код игры и существующие GLB не менялись, Tripo для фермы v3 не использовалась. Копию личного скриншота владельца в публичный репозиторий не добавляли.

## Что считать точным

- `layout-proposal.json`: 17 заданий, предложения центров 4×4 площадок и столбов; x вправо, z вниз/на юг. Границы x ±55, z ±37.5. У коровы две отдельные площадки, поэтому 17 задач соответствуют 16 персонажам/группам.
- `layout-technical.svg`: строго верхняя инженерная схема из этих данных. Ровно 10×10 одинаковых клеток, каждая 11×7.5. Это схема координат, **не нарисованные кодом игровые ассеты**. Воспроизводится `python3 assets-src/farm-v3/build-layout.py`.
- Проверено: все 17 площадок не пересекаются, расстояния до столбов 4–6. Для уток и козлят предложен общий столб (-20,5), на расстоянии 5 от обоих.
- Это пока предложение координат, не готовые значения для импорта в игру. Дороги, разрывы заборов, свободные зоны вокруг деталей, достижимость животного и механизмов требуют проверки при реализации. Художественная картинка не задаёт точные габариты.

## Ограничения Image-плана

`plan-v2.png` передаёт ту же общую раскладку, но сохранил небольшой наклон, изменил некоторые крыши/цвета и сделал нижний ряд сетки ниже остальных. Не снимать из него численные координаты. Для этого приложена точная SVG-схема и JSON. `concept-v1`, `concept-v2-access`, `plan-v1-superseded` — предыдущие итерации, не актуальный план.

В concept-v3 котёнок нарисован в высоком проёме амбара. В игре его нужно поставить на **низкую боковую площадку сеновала**, до которой достаёт реальный лифт; верхний проём на картинке не является техническим требованием. Пропорции амбара и его главного окна не должны вынуждать менять высоту лифта. Карусель, вентиляторы, насосы, фонтан, ворота, провода остаются функциональными частями игры; их работа важнее декоративного совпадения с картинкой.

## Переиспользовать имеющееся

Уже есть `barn`, `coop`, `stable`, `doghouse`, `hutch`, `haystack`, `beehive`, `tree-oak`, `tree-pine`, `bush`, `rock-cluster`, `flower-cluster`, обе `flowerbed`, `fence`, `fence-post`, `tractor` и все животные фермы, включая `fox-rig`. Конюшню, стог, ёлки и камни повторно не заказывать. Калитку сначала попробовать получить из имеющейся секции забора с отдельным шарниром. Возле кроликов использовать hutch, а не вторую будку для собаки.

После одобрения состава: вероятно нужны фермерский дом, силос, свинарник, навес, телега/тачка, колодец, пугало, мостки, ящик/бочка, рулон сена и модульные ряды культур. Сперва подтвердить, что нельзя собрать вариант из существующего без потери качества. Ряды культур делать небольшими повторяемыми GLB и инстансить, не моделировать тысячи отдельных стеблей. Детали/площадка/ворота никогда не перекрываются растительностью. Список не является заказом генераций.

## Первая расстановка в игре — 25 октября, m0120–m0126

`src/farm-decor.ts` передан Codex явно; здесь только данные, логика остаётся у Claude. `build-decor.py` воспроизводит файл и JSON, `scripts/check-farm-decor.mjs` независимо проверяет итоговый TypeScript через встроенный Node `stripTypeScriptTypes` (проверено на Node 25.6.1). `decor-authoring.json` сохраняет именованные проходы, игровые ограничения и будущие группы; `decor-layout.json` — ровно экспортируемые данные. `model-bounds.json` содержит измеренные GLB с указанным fit, а `decor-validation.json` — фактические габариты после текущего fit.

Игровые координаты уточнены по m0120, поэтому первоначальный `layout-proposal.json` остаётся концептом, а не актуальным источником механики. Пруд: (-40,3.5), радиусы 7.5×5. Корень ворот (30,17), стойки (28.4,16.4)/(31.6,16.4): северная ограда поля находится на z=16.4. Площадка мотора ворот — исключение из правила пустого квадрата 4×4, поскольку часть механизма стоит прямо у стойки. Остальные 16 площадок свободны от оград.

Первая версия использует только существующие GLB: 264 экземпляра до отсечения мелочей интеграцией, включая 60 деревьев; 29 связанных полилиний дорожек, 53 сегмента оград, шесть огородных грядок и поле. Минимальный зазор ограды от края дорожки 0.4; от оси лисьей тропы 1.2; пересечений оград с измеренными зданиями и рабочими площадками не найдено. Забор у будки сдвинут за её реальный габарит. Сохранил согласованные игровые размеры амбара width10.5 и курятника4.6; конюшня width10.

Дом, силос, свинарник, сарай, колодец и шесть видов культур пока есть **только в authoring**. Пока файлов нет, они не попадают в DECOR: это также сохраняет временные sprouts в коде Claude. После добавления GLB нужно повторно выполнить генератор и проверку и проверить новые габариты, прежде чем публиковать. Нынешний вид — первая расстановка, не законченная графика концепта: северо-западное место под дом и огород пока выглядят пустыми. Декоративная модель, не прошедшая фильтр рядом с задачами, в игре пропускается.

Встроенный браузер: локальная игра, q=1, 1180×820 и 390×844 через `qa-runtime.html` (CSS zoom только внешнего стенда для полного скриншота). Проверялись общий вид, читаемость игровых площадок, отсутствие чёрных моделей и загрузка GLB; прохождение сюжетов и реальная частота кадров на iPad этой проверкой не подтверждаются. Локальные снимки: `/tmp/gameios-visual-audit-2026-10-25/farm-decor-phase1-tablet.png` и `farm-decor-phase1-phone.png`.

По общему виду переданы Claude два замечания: трава чрезмерно насыщена, дорожки читаются плоскими жёлтыми полосами. Коррекция ground.ts — его зона. После интеграционного ревью следующий приоритет — дом, силос, объёмные ряды культур.

На телефонном снимке после «Показать всё» вид обрезает левый и правый край доски: передано Claude как ограничение обзора/камеры для исправления. В IAB повторяются сообщения MutationObserver.observe без URL (источник не определён); ошибок GLB или шейдеров в журнале не показано. Не заявляю нулевое число ошибок всей игры.

Перед коммитом: npm test — 17/17, npm run typecheck — успешно; независимый check-farm-decor.mjs — pass.
