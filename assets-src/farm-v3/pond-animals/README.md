## Оси и примерка

Нос/клюв **+X**, верх **+Y**, анатомическая левая сторона **+Z**. Исходники Studio смотрели +Z; применён yaw+90°. Низ Y=0 после декодирования, без отрицательных масштабов. Точные bbox, SHA256, преобразования и предлагаемый fit находятся в `axes-fit.json`; иерархия — в `*-report.json`.

- Лягушка: bbox X/Y/Z = 0,929258 / 0,833369 / 1. Предложенный `fit.height=0.47` сохраняет высоту прежней игрушки, получаются примерно0,524×0,470×0,564. Место(-34,6;8,4), yaw−0,6 из `src/farm.ts` не менялись. Подставки в GLB нет. Прежний круглый лист имеет диаметр0,9 и остаётся решением интегратора. **Существующий прыжок направлен в local−X**, поэтому для взгляда вдоль прыжка нужно повернуть именно визуальный GLB наπ внутри прыгающей группы либо осознанно изменить направление в коде. Сам ассет соблюдает контракт+X.
- Ворона: bbox X/Y/Z = 0,833496 / 0,650807 / 1 при раскрытых крыльях. Предложенный `fit.height=0.57` приблизительно соответствует высоте старой вороны с root.scale0,62; масштаб GLB нужно применить один раз. Это предложение интеграции, не выполненная замена в Pest.

## Крылья

В корне три именованных **группы**: `body`, `wing-left`, `wing-right`, каждая содержит свой mesh. Управлять группами, не `*-mesh`: дочерние mesh содержат преобразования декодирования квантованных позиций. Группы имеют единичный масштаб и нулевой поворот, плечевые translations в координатах GLB:

| Узел | Pivot X | Pivot Y | Pivot Z |
|---|---:|---:|---:|
| wing-left | 0.134942574 | 0.344498593 | +0.140000000 |
| wing-right | 0.133038824 | 0.347329989 | −0.140000000 |

Мах: `left.rotation.x=-a`, `right.rotation.x=+a`. Проверены ±55° и плавный `a=sin(t)*0.75`. Pivot не смещается, противоположное крыло при отдельном управлении остаётся неподвижным. При полном нижнем махе55° край уходит до Y≈−0,0182: использовать его в полёте с подъёмом группы минимум0,03 единицы GLB, на земле складывать крылья. Стендовая сложенная поза, EulerXYZ: левое(0,28;−1,05;0), правое(−0,28;+1,05;0). Это жёсткие игрушечные шарниры, не деформация перьев. Голова и хвост входят в body; независимого поворота головы в этом контракте нет.

Крылья выделены из исходного меша по узким плечевым воротникам, срезы закрыты треугольниками с тем же атласом. Выделение учитывает связность: все кончики перьев движутся с крылом. Неподвижных крыльев в body нет; выступающий сзади веер — хвост. На сильном складывании виден стык игрушечного плеча. Детали нельзя объединять/уплощать при последующей обработке.

## Проверки и ограничения

- `gltf-validator`: у обоих0ошибок/0предупреждений. Информационное сообщение: валидатор не проверяет EXT_meshopt_compression. Декодирование проверено реальным GLTFLoader с MeshoptDecoder и загрузкой WebP через img, как в игре.
- 24снимка: front/back/top/bottom/three/game для каждого животного на1180×660 и390×844. Дополнительно12снимков крыльев: вверх/вниз/сложены/только левое/только правое/только body на обоих размерах. Стенд `viewer.html`; измерения UI в `qa/views.json`, `qa/wing-poses.json`, живая анимация в `qa/animation-sample.json`. Консоль warn/error0.
- Низ визуально закрыт, подставок/окружения нет. У каждой части вороны одна связная компонента, граничных рёбер0 при допуске3e−5. Все исходные вершины сохранены с ошибкой менее0,0001 единицы, точные максимумы в `topology.json`; лишних неподвижных частей крыла нет.
- **Не заявляется manifold-топология.** В исходнике лягушки есть11неманифолдных рёбер и2очень коротких граничных ребра у лапы (каждое<0,0009), в кандидате их число не изменилось. Ворона имела9неманифолдных рёбер, после разделения по3на часть. Это особенности исходных Studio-сеток, не новые отверстия от среза. Самопересечения математически не проверялись; визуально значимых дыр не найдено. Не предназначено для3D-печати.
- `npm test`:21passed/4файла; `npm run typecheck`:passed. Проверены ассеты в отдельном просмотрщике. Реальный iPad/PWA/FPS, игровой рендер с постобработкой, полёт по полной траектории Pest и интеграция прыжка не проверены.

## Источники и воспроизведение

Референсы созданы встроенным Image по skill imagegen, приняты после собственного визуального сравнения со стилем существующих животных. Исходники PNG и полные точные промпты в `references/`. Заказы Tripo Studio: `orders.json`. Один заказ на животное, 25+25=50 **включённых** кредитов, баланс5700→5675→5650. Повторные генерации, API, Higgsfield, докупки, риг и клипы не использовались.
