# Проверка интеграции 37a1a7c

26.10.2026. Проверена ревизия **37a1a7cbed1edb9677ccd246f04d6480e799029f**, отдельный `git archive` без переключения общей ветки. Источники и GLB сверены по SHA-256, см. `snapshot.json`. Код игры и public не изменялись. Дополнительных генераций и расходов нет.

**Результат: лягушка прошла проверку направления и возврата; кинематика обоих крыльев вороны прошла числовую проверку. Визуальная проверка частичная:** получены игровые кадры лягушки и сложенной вороны на 1180×660. Детальные кадры махов и 390×844 не подтверждены из-за потери WebGL-контекста. Полное визуальное одобрение полёта не заявляется.

## Как проверялось

`review.html` — локальный стенд с явными кнопками. В iframe загружена настоящая игра с `?q=1`, вызван `startMap('farm', true)`. Сцена, освещение, загрузчик моделей, fit, методы `Life.tap/update` и `Pest.tap/update` взяты из проверяемого снимка.

Только в памяти QA-страницы общий `map.update` приостановлен, чтобы получать точные состояния. Renderer продолжает работать. Кнопки вызывают исходные методы животных с шагом 1/120 с. Это пошаговая проверка анимации, **не замер FPS**. Камера сфокусирована штатным `hooks.focus` на животном; это игровой масштаб после фокусировки, не начальный общий вид карты.

Для вороны через настоящий `connect` создан провод между двумя существующими ближайшими столбами. Начальная траектория посадки задана возле него, случайный `choose` обойдён. Посадка, складывание, ходьба и испуг используют исходный `Pest.update`; переход к бегству вызван `Pest.tap`. Автоматический выбор провода, peck/zapped, пользовательский raycast и полный свободный игровой цикл здесь не проверялись.

GLB в public совпадают с кандидатами: frog `380cc5a98dd466dbff9b4ae8a3daccdcb0c8f336934ebfd0e84f21fd396e84cc`, crow `381d8a6f12ef23e58988d5b37dac35760f6644449cad583a4ee5bd7fb095c167`.

## Сбой и границы проверки

После reload IAB сообщил `A WebGL context could not be created. Reason: Web page caused context loss and was blocked` и `Error creating WebGL context` в Stage. Повторная свежая вкладка сначала инициализировала игру без error-логов, затем 06:16:24 UTC записала `THREE.WebGLRenderer: Context Lost.` и стала показывать пустую сцену. Последняя короткая попытка 390×844 снова не создала контекст. Сохранены `browser-reload-webgl-errors.json`, `browser-recovered-then-lost.json`, `browser-mobile-blocked.json`.

Причина потери контекста не установлена. Эти данные не доказывают дефект GLB, игры в целом или общий отказ IAB. Отдельный успешный прогон другого чата не подменяет отсутствующие кадры этого аудита. Нативный fallback Safari был недоступен: инструмент вернул «The Mac is locked and automatic unlock could not unlock it». Разрешения и настройки браузера не менялись; новых попыток нативного доступа после этого не было.

Непроверены: детальный вид плечевых соединений во всех фазах маха **в интегрированной игре**, визуальный полёт на 390×844, настоящий iPad/Safari, touch/raycast, PWA/offline, FPS, тепловая стабильность и качество q2. Прежняя проверка отдельного asset viewer описана в соседнем README и не заменяет эти пункты.
