Tripo rig-only v3.0-20260909 / quadruped. Стоимость 25 API-кредитов: 215 → 190.
Rig-check бесплатный, riggable=true. Это исходный пилот; следующие результаты — ниже.

Внешность сохранена: после одинакового fit по ширине максимальное расстояние
вершины rig до исходной модели — 4.55e-7 ширины. Tripo изменил 8000 → 7999

точные TRS костей: NodeIO иначе убирает почти единичные scale/rotation, и проверка
защищённого скелета отказывает. Исправление проверено на fox-rig и motor.

## Ограничение качества

**Для полноценной ходьбы этот pilot не принят.** Задняя нога со стороны +Z получила
только bone_20, без цепочки колено/копыто; её веса захватывают вымя и круп.
Вторая задняя нога имеет цепочку, но её конечная кость влияет и на часть первой.
Нет отдельных костей ушей/челюсти. Не выдавать эти недостающие возможности за готовые.

Мягкие повороты головы (±15°) и хвоста (±20°) визуально проверены. Claude принял
использование для стоящей коровы (m0181). Заднюю ногу не чинить: ходьба для неё
не нужна. Следующих героев проверять по одному на чистые движения головы/хвоста;
если шея/голова не выделены, пропускать модель и оставлять изгиб кодом.

## Оси и карта костей

Как статичная корова: вперёд +X, вверх +Y. Низ rig уже на Y=0.
model('cow-rig', {width: ...}) без rotateY даёт то же положение, что cow.
Клонировать через SkeletonUtils, сохранять всю Armature, учитывать skinned mesh в кэше.
GLTFLoader удаляет двоеточия из name; исходное имя остаётся userData.name.
Точные имена, родители, координаты и роли: cow-bones.json.

| Что двигать | Исходное имя GLB | Имя после GLTFLoader |
| --- | --- | --- |
| Шея, поворот всей головы | tripo::Head_1 | tripoHead_1 |
| Верх шеи | tripo::Head_2 | tripoHead_2 |
| Голова | tripo::Head_3 | tripoHead_3 |
| Основание хвоста | bone_1 | bone_1 |
| Середина / низ / кончик хвоста | bone_2 / tripo::Tail_0 / tripo::0_Left_Limb_0 | bone_2 / tripoTail_0 / tripo0_Left_Limb_0 |
| Передняя нога −Z | bone_12 → bone_13 → bone_14 → bone_15 | без изменений |
| Передняя нога +Z | bone_16 → bone_17 → bone_18 → bone_19 | без изменений |
| Задняя нога −Z, ограниченно | tripo::0_Right_Limb_1 → _2 → _3 | tripo0_Right_Limb_1 → _2 → _3 |
| Неполная задняя нога +Z | bone_20 | bone_20 |

tripo::Head_0 — грудной узел и родитель обеих передних ног: НЕ использовать для
поворота только головы. tripo::0_Right_Limb_0 — таз/корпус, НЕ отдельная нога.
Поворот кости добавлять к rest quaternion, переводя ось из пространства модели
в пространство родителя. Пример проверки — qa.html.

## Воспроизведение

    node scripts/prepare-hero-rig-input.mjs public/models/cow.glb assets-src/raw/farm-hero-rigs-2026-10-25/cow-input.glb

Rig уже выполнен. Не повторять платную операцию для пересборки.

    node scripts/optimize-mobile-models.mjs --input assets-src/raw/farm-hero-rigs-2026-10-25/compress-input --output public/models --texture-source public/models/cow.glb --report assets-src/farm-v3/hero-rigs/cow-compression.json cow-rig

qa-frame.html открывает сравнение в 1180×844 и 390×844.
qa.html показывает исходную и rig-модель при одинаковом fit, ракурсы,
наклон/поворот головы, хвост и проблемные ноги. Кнопка анимации гоняет выбранный
шарнир вокруг исходной позы; это диагностическая проба, не игровой клип.
Параметр ?rig=/...glb позволяет проверить сырой результат до сжатия.
