## Что именно проверяет стенд

`review.html` открывает существующий main.ts через iframe `/?q=1`. Для каждого столба выбирается фаза его задания и тот же focus/view, который использует игра. Выбор задания воспроизводит focused/picked из обработки нажатия на персонажа; остальные задания не объявляются пройденными. После отрисовки камера фиксируется через тот же focus helper перед измерением, чтобы подсказка от предыдущего задания не сдвинула промежуточный ракурс.

От attachPoint обеих клемм идёт луч к фактической PerspectiveCamera. Проверяются загруженные Mesh/InstancedMesh в scenery с учётом видимости родителей и материалов. Непрозрачным препятствием считается opacity≥0.9 с depthTest; полупрозрачные поверхности, персонажи и life.extra идут отдельными списками. Это консервативная проверка геометрии. Собственная геометрия столба, спрайты/рука-подсказка, CSS-панели и расставленные позднее игроком детали не входят в этот тест. Положение на экране дополнительно сравнивается с холстом и существующими stage.insets.

Метод проверен положительным контрольным случаем: **только в QA** на время трассировки в сцену добавлен прежний boxHouse(5,3.4,4) в точке(26,21), через существующий экспорт storymap.boxHouse. После измерения удаляется с освобождением ресурсов; src и DECOR не меняются. На обоих размерах метод обнаруживает **2 скрытые клеммы STATION_POLE**. Контрольные JSON отдельно помечены `historicalRoofControl:true` и не смешиваются с итогами. Это реконструкция известного старого препятствия, не восстановление всей старой версии города.

Визуально дополнительно осмотрены STATION_POLE и CLUB_POLE на390, BAKERY_POLE, HOUSE_POLE и SCHOOL_POLE на1180; скриншоты в qa/. Результат не доказывает удобство попадания пальцем, контрастность, отсутствие временных перекрытий анимациями или прохождение всех заданий.

## Повторить

1. Запустить `npm run dev`.
2. Открыть `/assets-src/city-v2/pole-visibility/review.html`.
3. Нажать «Город заново», затем «Проверить все»; дождаться «Столбов14». Таблица и JSON расположены ниже игры.
4. Повторить для390×844. После resize дождаться изменения размера перед проверкой.
5. «Старая крыша: контроль» должен отдельно дать2перекрытия. «Осмотреть» возвращает нормальную проверку выбранного столба.

При смене будущих GLB, расположения зданий или кадрирования тест повторить.
