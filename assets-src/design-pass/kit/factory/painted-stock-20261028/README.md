## Размеры и опора

`placement.json` содержит точные значения. Видимая ширина сохраняет прежний `size` из `racks/goods/bays/pallets/barrels` LAYOUT6. Размер полного прозрачного холста больше видимой ширины. Пиксели считаются от левого верхнего угла **всего** WebP. Точка основания — центр передней линии опоры: между ножками стеллажа, центральная ножка поддона, между передними дугами днищ бочек. Поэтому у стеллажа/бочек сам центральный пиксель может быть прозрачным.

## Подключение через cards с сохранением instancing

Взять `kitPieces('factory','factory-rack-painted')[0]` и аналогичные pallet/barrels. Для каждого вида собрать все spots в одну группу. Пусть `(iw,ih)` — размер WebP, `(ax,ay)` — опора, `span` — ширина силуэта alpha≥115: **869 / 489 / 428** соответственно.

1. В `cards()` передать прежние x/z, но `size = S * iw / span`.
2. После создания группы **один раз** сдвинуть единичную геометрию её InstancedMesh: `geometry.translate(.5-ax/iw, (ay/ih-1)*ih/iw, 0)`.
3. Группа и инстансы остаются на y0, x/z не сдвигаются. Обычные ориентация, материал и нормали `cards()` сохраняются: Standard, alphaTest .45, DoubleSide, noAO=true. Не добавлять proxy/pick/collider.

Три точных сдвига единичной геометрии:

- rack: `(-0.00048828125, -0.16015625, 0)`;
- pallet: `(-0.00065104166666663, -0.07421875, 0)`;
- barrels: `(0, -0.06510416666666667, 0)`.

Это учитывает нижнее прозрачное поле без обрезки и без отдельных draw calls на каждый экземпляр. В fixture три группы карточек: 3 стеллажа, 14 поддонов, 5 групп бочек. Прежние `standees` и их тени заменяются условно только при готовности новой текстуры; при её отсутствии оставить старую ветку. Не рисовать старый и новый вариант одновременно.

Короткая мягкая тень использует имеющийся `farm/blob-shadow` через `patches`, одна instanced группа на вид: x=`spot.x+S*.08`, z=`spot.z-referenceDepth*S/referenceWidth*.25`, размер=`S*.55`, y=.009, order3. Старую большую тень standees не складывать с новой. Встроенная мягкая alpha-тень рисунка преимущественно отсекается .45.
