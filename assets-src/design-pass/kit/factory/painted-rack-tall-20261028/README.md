## Размещение

Сохранить три нынешних x/z/size у северной стены. При готовой текстуре B: `piece:'factory-rack-tall', at:[512,684.5], span:946, deep:1.4/5.5`. В `painted()` прежний полный алгоритм: fullWidth=S*1024/946, затем **один раз** translate unit geometry `(0,-0.08154296875,0)`. При S5.5 fullWidth=5.953488372093023. Опора — середина передней линии двух пяток, центральный пиксель прозрачен; визуальная точность ±1 пиксель. Нового pick/collider нет.

Если B не загружен, использовать A с **его** at/span (512.5,604 /869), затем прежнюю цепочку fallback. Нельзя подставлять A в геометрию B или складывать обе картинки. Направляющая высотой4.2 — только референс. Фактическая высота непрозрачного силуэта в плоскости карточки при ширине5.5: B3.69767 против A2.74684 (+34.6%); это не физическая мировая высота.

## Предложение теней по m0598

В существующем `painted()` заменить только spots для одного `patches()`:

```js
spots.map(s => ({
  x: s.x + s.size * .45,
  z: s.z - s.size * kind.deep * .5,
  size: s.size * 1.35,
}))
```

Та же farm/blob-shadow, y.009, order3, штатные материал и opacity1. Прежнюю тень .55S удалить/заменить, не накладывать вторую. Дополнительных картинок/шейдеров/draw calls не нужно; количество instances прежнее. Временный стенд содержит оба варианта для сравнения, скрывает ненужный. У prop-карточек тень остаётся внутри того же Life holder, raycast=()=>{}; не менять jump/wobble/pick/координаты. Это мягкая декоративная тень вправо/назад, не физическая тень старого GLB и не обещание совпадения с направленным светом.

Формула .25S/глубина*.35/размер1.05S была слишком слабой — отклонена. Итог .45/.5/1.35 просмотрен под будкой, шкафчиками, рампой, стеллажами и западным складом. Сравнения в comparison.html, точный контракт placement.json. Глобальная проверка соседей остаётся за интеграцией.
