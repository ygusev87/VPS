# Предложение m0617: один слой у рельсов

Статус: анализ существующей сцены; генерация и изменение пола не начаты. В текущем указании владельца есть «пол не перерисовывать»; уточняется, допускается ли отдельная декаль поверх прежней основы.

На 220cd34 центр RailCart: X=-41.85, Z=7.425. Масштаб 1.5. Плата 9.2×1.7 локально, то есть X[-48.75,-34.95], Z[6.15,8.7]. Рельсы длиной 8.6 локально, после масштаба 12.9; находятся на Z=6.9 и 7.95. Колёса едут по рельсам, поэтому резиновые следы на бетон под ними добавлять нелогично. Существуют масляные пятна и вытянутая масляная декаль рядом; их дублирование следует исключить.

Предварительный прямоугольник зоны: X[-49.6,-35.6], Z[5.4,9.45], 14×4.05. Этот пилот охватывает западную и среднюю часть плиты, находится внутри существующего ограждения X[-52.35,-35.35], Z[4.925,13.925]. Восточный выход рельсов и участок за рамкой остаются вне пилота.

Слой-кандидат для проверки: decal(rect, map, 0, 0.011, 0), без поворота, U→+X, верх изображения→−Z. Это Standard с receiveShadow=true и depthWrite=false, чтобы получать реальное освещение. Порядок 0 ниже существующих масляных декалей и проходов (1), рамки (2), мягких теней (3). Прозрачный контур не добавляет pick/collider; raycast noop, noAO=true, castShadow=false. Окончательные opacity/размер не приняты.

Предмет рисунка при разрешении: редкие потёртости и небольшие следы эксплуатации вокруг плиты, без новой основы бетона, без нарисованных рельсов/тележки/теней, без нового сплошного периметра поверх существующей жёлтой рамки. Один отдельный пилот до любых следующих зон.
