## Сохранение тени

Семь прежних брусьев нужны как невидимый источник настоящей тени. Дополнительного blob нет; плоская карта тень не отбрасывает.

**bakeGroup создаёт новые материалы и теряет colorWrite/depthWrite.** Если скрыть брусья до обычного `bakeGroup(hall)`, они снова появятся. Безопасный вариант:

1. Собрать принятые исходные колонны в отдельную группу и выполнить для неё `bakeGroup`.
2. После bake поставить материалам `colorWrite=false`, `depthWrite=false`; оставить `visible=true`, `castShadow=true`.
3. Добавить этот отдельный меш в scenery, отключить его raycast. Остальной hall проходит прежний bake.

Получается один меш тени из 84 исходных треугольников и один batch карт. Stage исключает depthWrite=false из AO; shadowmap сохраняет прежний объём. Не дублировать старую тень и не добавлять blob через общий helper `painted`.
