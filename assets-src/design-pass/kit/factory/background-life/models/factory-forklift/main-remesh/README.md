# Локальное закрытие стыков погрузчика — эксперимент

Не использовать в runtime: подъём ещё не принят. Исходный `../static-candidate.glb` не менялся, новых заказов Tripo нет.

`build.mjs` сохраняет все 3590 исходных треугольников и исходный атлас. Два неплоских контура (13/15 вершин) закрываются 11/13 треугольниками с каждой стороны: всего 3638. Перебираются 2048 направлений проекции; динамическая триангуляция запрещает диагонали, совпадающие с исходными рёбрами. Это устранило дефект предыдущего способа, который терял одно ребро, а прямое заполнение создавало рёбра с четырьмя гранями.

После Meshopt-декодирования `body` (3462 tri) и `forks` (176 tri) имеют по две противоположно ориентированные грани на каждом сваренном ребре; вырожденных треугольников нет. Это проверка рёбер, а не доказательство отсутствия всех самопересечений. Формат GLB: 104516 байт, один OPAQUE материал, 512 WebP, validator 0 ошибок/предупреждений. Прежняя коррекция контакта колёс в нижних 7 мм сохранена; это локально обработанная сетка, не нетронутый Tripo-результат. Имена групп существуют только в этом эксперименте, публичной модели по-прежнему нет.

`validate.mjs` проверяет непрерывные интервалы пересечения поверхностей при переносе вил по Y от .001 до .65. Найдены 303 пары контактов/пересечений, все с мачтой или новыми закрытиями; с прочими частями корпуса пар нет. Касания не исключались как «подшипник» автоматически. Выборочная проверка внутренней точки подтверждает проникновение: при Y+.2 точка (0.469856,0.818929,0.707484) лежит внутри неподвижной геометрии на глубине около .02648. Это не точное глобальное максимальное проникновение.

Значит, закрытия дыр недостаточно: для подъёма требуется переработать сопряжение каретки и направляющих с зазором. Простое движение всей мачты неверно. Вариант фиксированных вил для фоновой езды остаётся на решении Claude (в исходной задаче отдельные вилы — «если получится»). Паллет/маршрут/полная фабрика и физический iPad здесь не проверены.

Пересборка из корня проекта: `node assets-src/design-pass/kit/factory/background-life/models/factory-forklift/main-remesh/build.mjs`, затем рядом `validate.mjs`. Локальные входы: сохранённый raw GLB и `../candidate/split-analysis.json` из worker; исходные скрипты inspect-segments/inspect-split сохранены. `articulation-geometry.json` — воспроизводимый промежуточный файл, не коммитится. QA: `qa.html`, нативные кадры в `qa/`, текстуры оригинальные; только локальные кнопки поз и ракурса.
