# Полосы и масляные декали завода B

Пять исходных PNG созданы встроенным image_gen, по одному initial на ассет, без правок и внешних заказов. Полные оригиналы сохранены в `../sources/`, prompts.json хранит запросы и технические crops. build.mjs воспроизводит только crop/resize/sRGB/WebP85 с исходной альфой; изображения не дорисовываются кодом.

Runtime: walkway256×2048, hazard128×2048, rail256×2048, oil-a/b512². Всего **418852 байта**. Хэши, альфа и размеры — manifest.json. Для полос удалены пустые боковые поля; hazard выбран по совпадению диагональной фазы, rail содержит7шпал и период4.2ед. Полные исходники не обрезаны.

## Подключение

Точные рекомендуемые параметры — integration.json. Walkway подходит текущим wide1.1/length6.4, видимая дорожка около1.584ед при lane1.6. Hazard: для ширины краски0.3 использовать ribbon0.336, repeat4.36 (нынешние2.4сжимают диагональ). Rail: полный ribbon1.273289, wide1.061074 для lane1.2, repeat4.2; номинальная колея0.7 по центрам рельсов, шаг7шпал0.6. Исходные центры/ширина измерены, небольшая неровность нарисованных кромок сохранена. Рельсы в игровом коде пока не заменены; движущиеся колёса/физика остаются Claude. Нельзя рисовать одновременно прежние шпалы и новую полосу.

Oil: размер декали1.6 как в текущем коде. Это сухие тёмно-коричневые следы на светлом полу, не физически корректное мокрое масло. Полупрозрачные края сохранены, прямоугольного фона нет.

## Проверка

qa.html: нативные браузерные кадры с iframe390×844 и1024×768, реальные масштабы32/70px/ед, повтор полос и светлый/белый/тёмный фон. Семь JPEG в qa/. Рельсы продолжаются без видимого скачка, шаг шпал ровный; диагональная фаза hazard не ломается. Масло не имеет прямоугольной подложки. Снимки пола используют текущий кандидат worker только как фон; его приёмка отдельно.

Попиксельная бесшовность не заявляется: средняя RGB-разница top/bottom (из255, на светлом фоне) walkway7.72, hazard5.99, rail1.07; естественные потёртости могут менять тон на стыке. На проверенных масштабах явной полосы-разрыва не видно. Рельсы проверены по нарисованной колее; игровой кадр вагонетки ещё нужен от Claude. iPad/PWA/FPS этим статическим стендом не проверялись.
