# Рисованная задняя стена

`public/textures/kit/factory/factory-wall-back.webp`: 1024×256 (4:1), 41310 байт, добавлена в factory/kit.json. Исходник source.png, точный промпт generation.json; один встроенный image_gen. build.mjs только кодирует полное изображение. Генератор вернул 2172×724 (3:1): для заказанного 4:1 высота относительно равномерного масштаба сжата на25%; без обрезки и дорисовки.

Main осмотрел исходник и два native IAB кадра1180×820/390×844: один тайл, повтор320/640px, крупный фрагмент. Console0, horizontaloverflow0. На landscape QA-странице есть намеренная вертикальная прокрутка. Повтор визуально согласован; это не попиксельная бесшовность, borderdifference в report.json. Тонкая нарисованная нижняя полоса сохранена.

Контракт: плоскостьXY, normal+Z, U→X, V вверх, один повтор16×4world (либо4H×H при другой высотеH); repeatU=wallLength/(4H), repeatV=1. sRGB/unlitwhite/OPAQUE/FrontSide/depthTest+write, без shadow/interaction. Claude размещает на настоящей карте, проверяет оконные/трубные дубликаты, часы/щит и проходы. Полная карта и касания этим стендом не приняты.
