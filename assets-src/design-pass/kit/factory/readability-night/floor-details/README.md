# Пять напольных деталей

Приняты для интеграции: следы шин, белая стрелка, полоса кабель-канала, решётка и жёлто-чёрный уголок. Вместе с `../floor-weather/` закрывают все девять декалей m0537. Встроенный image_gen: один исходник на предмет, без повторных генераций и ручной дорисовки. Только resize/WebP90 alpha100.

| Asset | Полный холст, world X×Z | Opacity |
|---|---|---|
| factory-floor-tyre-tracks | 5×1.667 | .40 |
| factory-floor-arrow | 1.7×1.7 | .80 |
| factory-floor-cable-channel | 3.6×1.2 | 1 |
| factory-floor-grate | 1.6×1.6 | 1 |
| factory-floor-hazard-corner | 1.6×1.6 | .80 |

Плоскость XY, rotationX −π/2, normal +Y, U вдоль X; верх изображения направлен −Z. Стрелку и уголок можно повернуть вокруг Y. sRGB, MeshBasicMaterial white, transparent true, depthWrite false, depthTest true, FrontSide, alphaTest 0. Стенд использует смещение +.015 над полом; Claude выбирает фактическую высоту и позиции. Не перекрывать подсказки, контуры заданий и провода. Без collider, shadow и pick.

Шины и канал имеют законченные края и прозрачные поля: это отдельные полосы, не бесшовные тайлы. У каждого по два крайних пикселя alpha1/255, сохранены; видимого обрезания на стенде нет. У остальных край полностью прозрачный. Решётка содержит шесть прорезей (генератор не повторил семь из prompt), это декоративное изображение углубления без отверстия в геометрии.

Main осмотрел четыре native кадра 1180×820 и 390×844: светлый вид сверху и тёмный наклонный. 5/5 загружены, console warning/error 0, overflow 0. Результат в review.json, кадры в qa/. Полная игровая расстановка, перекрытия и физический iPad/PWA ещё не приняты.
