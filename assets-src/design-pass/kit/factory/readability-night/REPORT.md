## Очередь реализации

1. Claude: рабочий масштаб одной станции, постоянно доступное облачко и явные источник/цель; маршрут продукта с видимой передачей; проверить физическое касание. Не увеличивать по отдельности связанные валы/пивоты. Полный обзор оставить отдельным режимом.
2. Единственный worker после текущих6: открытый грузовик, узнаваемая игрушка, готовая коробка по `worker-priority-04.json`. Это новые отсутствующие игровые модели, не повтор принятых корпусов.
3. Main: рисованная поверхность конвейера; затем модульные окна/стеновые трубы/плафоны и применение уже готовых stockcards. Статичные новые GLB на эти объекты не заказываем.
4. Повторная приёмка только изменённых сцен: цель видна без слов; облачко не за геометрией/панелью; управляющий элемент и результат вместе в рабочем кадре; груз сохраняется на всех переходах; никакое касание не зависит от попадания в 10px рисунок. Ориентир видимой активной области44–56CSSpx — предложение UX, не проверенный на физическом iPad результат.

Проверка текущего состояния не равна утверждению всей фабрики: main не завершал12заданий, не измерял FPS/VRAM, не слышал новые фразы, не тестировал физический iPad/PWA. Старые принятые GLB не переоценивались без дефекта. Временный сервер сначала не имел define __BUILD__, это исправлено в конфиге snapshot; после перезагрузки новых ошибок не было. Сервер/вкладка закрыты.
