# Завод — четыре референса будущих GLB

**Четыре изображения приняты как концепты для изготовления 3D. Фактические GLB ещё не созданы.** Пакет не заменяет модели финальными карточками и не подключается к игре. Внешних 3D-заказов, платных API и загрузок файлов не было.

| Концепт | Целевой размер Ш×В×Г | Что остаётся отдельным |
| --- | --- | --- |
| `concepts/lever-box.png` | 1.5×0.4×1.1 | Рычаг и его ручка; на крышке только ◀ ■ ▶ |
| `concepts/rail-cart.png` | 1.3×0.8×1.0 | Четыре колеса в узлах `wheel-*`; отдельный скрываемый груз `load-coil` |
| `concepts/shaft-motor.png` | 1.1×0.25×0.9 | Вертикальный вал, его воротник и шестерня; в корпусе пустой подшипник |
| `concepts/socket-board.png` | панель 2.6×1.0×0.2 | Вилки, шнуры и активные клеммы; три формы на лицевой текстуре |

Каждый PNG1254×1254 сохранён byte-exact, без обработки; суммарно7507800bytes. По одному встроенному вызову imagegen на предмет: всего4, повторов и правок0. Фон белый, мягкий вид3/4 сверху; бирюзовая эмаль, сталь и жёлтые детали соответствуют выбранному factory-industrial-b и готовому токарному корпусу main. Сильнее выраженная мелкая потёртость переносится в текстуру при моделировании.

**Размеры в таблице — цели, а не измеренная геометрия изображения.** Точный bbox, оси, крепления, отдельные узлы и бюджет ≤4000 треугольников /1 материал /WebP512–1024 проверяются после изготовления GLB. У вагонетки видны три колеса, четвёртое скрыто ракурсом; будущая модель должна иметь четыре. Положение отверстия мотора фиксируется по workshop.ts: x0,z−0.35 при центре корпуса z−0.1. Его точный отступ нельзя сертифицировать по картинке. У socket-board формы переносить как рисунок на поверхности, без лишней геометрии гнёзд.

## Проверка

Внутренний браузер: contact sheet и каждый из4предметов на390×844 и1024×768 —10проверок,10просмотренных оригинальных JPEG,0ошибок консоли и0горизонтальных переполнений. На мобильном читаются стрелки/квадрат реверсора, катушка и колёса, пустое отверстие мотора, все3формы панели. Нет рычага, валов, шестерни, вилок, проводов, рельсов или общей платы.

`npm test`:17файлов,88тестов PASS. `npm run typecheck`:PASS. Это проверка концептов, не производительности 3D в игре и не физического iPad.

`qa.html` — просмотр через локальный HTTP-сервер; `qa/` — кадры и результаты браузера. `prompts.json` содержит точные аргументы всех4вызовов, `generation-log.json` — исходные пути и SHA, `references.json` — прочитанные контракты/стиль. `build.mjs` только проверяет оригиналы и создаёт manifest; изображения не меняет. `model-contract.json` содержит требования к будущим GLB и различия с текущими процедурными деталями.

Парк из d2b6e7b принят main после исправления положения в471ac7e и включён в kit25 коммитомb3a02b9. Само изображение не менялось; более широкий fallback остаётся отдельным ограничением. Своя зона — только machines-secondary/. Src, public, sources, kit.json, shared read/ack и push не затрагивались.

Геометрический handoff дополнен в `geometry-handoff.md`: уточнены системы координат колёс, отдельная видимость катушки при разгрузке, зазоры рычага/вала, позиции клемм и влияние общего bbox при вписывании. Данные сверены с кодом, реальной GLB-проверки пока нет.
