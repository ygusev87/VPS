Для точного контакта использовать anchor изmanifest либо учестьэтотзапас приразмещении. При обычном cards() размер3.2/3.1 даст силуэт примернона1%уже; это допустимое упрощение интегратора. Нельзя растягивать PNG в квадрат. Ракурс иллюстративный, не восстановленная геометрия.

Полки, трубы, две катушки и пустая кабина с двумя опущенными вилами читаются при32/70px/ед. Нативные браузерные пятьJPEG при390×844 и1024×768 показывают бетон/белый/тёмный фон. В видимых отверстиях нет подложки; по краям рамки толькоalpha<=5, заметного обрезанного объекта нет. Исходные изображения имеют запас; тень не запечена, использовать blob-shadowфермы.
