## Ограничения для моделирования

Изображения задают вид, а размеры и пустоты нужно проверить уже в геометрии. Подробный контракт — modeling-contract.json, исходный бриф — ../../FACTORY-KIT.md.

- Щиток показан низким горизонтальным лотком с петлями слева. В текущем WireBox дверца закреплена сзади. Нельзя просто растянуть картинку до высоты 1,1 и загородить плитки: оставить читаемую сверху полость и передать дверцу отдельным узлом или оставить её кодом. Сторону петли при интеграции согласует Claude.
- У пресса станина соответствует ширине 1,9 и высоте 2,3; наковальня может выступать до глубины 0,8, как в текущем коде. Внутри не должно появиться перемычки или слитого ползуна.
- У токарного генератор нарисовал статичную шкалу на передней бабке, хотя запрос предполагал пустое крепление. Это подходит брифу с циферблатом; активная стрелка остаётся кодом. Текущий код поднимает циферблат до 1,55, выше корпуса 1,2 — высоту нельзя считать окончательно совпавшей по одному PNG.
- Мелкая сетка подъёмника — риск для лимита треугольников и прозрачных отверстий. При приёмке GLB обязательно проверить, что шахта не заполнена непрозрачной стеной и сохраняет место для кабины.

Общий предел будущего GLB: 4000 треугольников, один материал, текстура WebP 512–1024. Общую игровую плату, клеммы и подвижные части не запекать в корпус. Ни одна будущая модель пока не проверена по этим пунктам.

## Проверка изображений

В локальном браузере просмотрены общая сетка и пресс при 1024×768, каждый корпус отдельно при 390×844. Шесть исходных JPEG-снимков в qa/; loaded 4/4, errors пуст, горизонтального переполнения нет. Проверены пустые пролёты, отсутствие платы, подвижных деталей и фоновой тени. Детали корпуса имеют собственное освещение; белый фон не заявляется прозрачным.

qa.html/viewport.html — локальная страница просмотра; запуск из корня проекта: node assets-src/design-pass/kit/factory/machines-primary/preview.mjs. Это проверка референсов, не игрового WebGL, анимации, FPS или физического iPad. Результат обязательных проверок проекта записан в progress.md.

## Уточнение интегратора m0410

Дверца щитка должна остаться на севере (−Z), открываться вверх за плитками; левые петли референса не переносить в итоговый корпус без исправления. Циферблат токарного — отдельный кодовый элемент с центром (−0,7; PLATE_TOP+1,25; +0,5), радиусом0,3, лицом на юг; в модели оставить плоское крепление. Выступ наковальни0,8 подтверждён. Контракт JSON обновлён; картинки не перерисованы.
