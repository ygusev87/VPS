# Завод B: четыре референса статичных корпусов

Готовы **изображения для последующего изготовления моделей**, а не GLB. В игру и kit.json ничего не добавлено. Четыре исходных вызова image_gen и две точечные коррекции по m0410 (петли щитка и отсутствие шкалы токарного); внешних загрузок и 3D-заказов не было. Стиль взят из выбранного владельцем factory-industrial-b.

Цвета/геометрия не правились программно. Превью вместе 345 508 Б; это локальный обзор, не игровой бюджет.

## Ограничения для моделирования

Изображения задают вид; размеры и пустоты проверяются в геометрии. Точный контракт — modeling-contract.json, исходный бриф — ../../FACTORY-KIT.md, решение интегратора — m0410.

- Щиток: выбран concepts/factory-cabinet-v2.png, две петли на заднем северном краю (−Z), отдельная дверь открывается вверх за плитками. Лоток пустой под 2×2 клетки. Версия1 с левыми петлями сохранена для истории и не идёт в моделирование. Нельзя растянуть корпус до высоты1,1 так, чтобы он загородил плитки.
- Пресс: статичная рама 1,9×2,3×0,6, наковальня может выступать до глубины0,8 (Claude подтвердил). Внутри не должно появиться перемычки/слитого ползуна. Кнопки отдельно.
- Токарный: выбран concepts/lathe-v2.png. Статичный циферблат удалён, сверху передней бабки сохранена плоская площадка. Код добавляет отдельный dial: центр(-0,7;PLATE_TOP+1,25;+0,5), r0,3, лицом на юг. Пустой пролёт, подвижные шпиндель/заготовка/стрелка отсутствуют. Версия1 с нарисованной шкалой сохранена только для истории.
- Подъёмник: мелкая сетка — риск для лимита треугольников и отверстий. При приёмке GLB проверить, что шахта не заполнена стеной и не мешает кабине.

Общий предел будущего GLB: 4000 треугольников, один материал, текстура WebP512–1024. Плату, клеммы и подвижные части не запекать в корпус. Ни одна будущая GLB пока не изготовлена и не проверена.

## Проверка изображений

В локальном браузере просмотрены общая сетка и пресс при 1024×768, каждый корпус отдельно при 390×844. Шесть исходных JPEG-снимков версии1 и ещё три кадра выбранных исправлений в qa/; loaded 4/4, errors пуст, горизонтального переполнения нет. Проверены пустые пролёты, отсутствие платы, подвижных деталей и фоновой тени. Детали корпуса имеют собственное освещение; белый фон не заявляется прозрачным.

qa.html/viewport.html — локальная страница просмотра; запуск из корня проекта: node assets-src/design-pass/kit/factory/machines-primary/preview.mjs. Это проверка референсов, не игрового WebGL, анимации, FPS или физического iPad. Результат обязательных проверок проекта записан в progress.md.


Исправления воспроизводимо выбраны через selectedSource/selectedPreview в prompts.json; полные запросы правок и их исходники в corrections.json. Первые PNG и превью сохранены. Для выбранных исправлений просмотрен общий вид1024 и каждый отдельно390: loaded4, errors[], без overflow.

Подробные числовые оболочки движения, отдельная крыша Lift для котёнка и отверстие штока пресса: geometry-handoff.md. Это подготовка приёмки, не проверка отсутствующих GLB.
