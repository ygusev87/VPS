# Поддон и три бочки

Две прозрачные карточки для FACTORY-KIT §3/m0422, готовые к интеграционному ревью. Суммарно **268172 B**. Поддон несёт ровно три ящика; группа бочек состоит ровно из трёх закрытых синих бочек. Самостоятельные одиночные бочки в игре остаются кодом. Общий `kit.json`, `src`, main `decor-large` и общая очередь не менялись.

Anchor — нижний центр видимого bbox, не центр прозрачного файла. Размер прямоугольника рассчитан так, чтобы его видимая часть имела запрошенную ширину: `rectangleWorldWidth = visibleWorldWidth / visibleWidthFactor`; высота выводится из aspect. Если интегратор уже нормирует по видимому bbox, повторно применять компенсацию не нужно. При другой обработке альфы/порогах границы следует пересчитать. Данные в `manifest.json` относятся к alpha>=8 из255; порог использован только для измерения и выбора crop, саму альфу он не меняет.

Запрошенная камера — ортографический вид3/4,≈52° сверху от горизонтальной плоскости. Это изображение модели, а не калиброванный3D-рендер: точность52° не заявляется. Для бочек отдельной правкой увеличен наклон камеры; круглые крышки раскрылись и все три читаются. Нижний центр привязки не является измерением физического центра основания в3D.

## Происхождение и упаковка

Встроенный `image_gen.imagegen`, **4 вызова:2 initial+2 targeted edits**, по одной правке каждого объекта. `prompts.json` содержит начальные запросы, `correction-prompts.json` — точные запросы правок. Причины: у первого поддона нижняя опора доходила до последней строки исходника; у бочек исходный ракурс был заметно ниже заданного. `iterations/v1/` хранит первые PNG, промпты и журнал. `generation-log.json` хранит обе версии, SHA, пути генератора и архивную входную картинку каждой правки.

Полные выбранные PNG в `../sources/` сохранены побайтно. Техническая упаковка: bbox по alpha>=8, запас2% от длинной стороны с ограничением границами исходника; пропорциональное уменьшение без растяжения до длинной стороны1024/768; sRGB/WebP quality88, alphaQuality100. Нет новой рисованной маски, дорисовки, удаления тени алгоритмом, перекрашивания, добавленного пола или нового фона. В сохранённом прямоугольнике исходная альфа лишь ресэмплируется вместе с изображением. Сравнение альфы перед WebP-кодированием и после декодирования: 0 различающихся пикселей у обоих файлов. Исходные PNG не изменены.

Crop источников: поддон `(left12, top0, width1278, height1218)`; бочки `(left86, top17, width1146, height1148)`. Прозрачная шапка и лишние поля убраны; экспорты сохраняют пропорции и не дополняются до квадрата. У поддона нижний запас меньше2% из-за границы исходного canvas, но исправленный контур целиком внутри и видимая альфа не касается внешних строк/столбцов.

Воспроизведение из корня проекта: `node assets-src/design-pass/kit/factory/decor-small/build.mjs` (проектный `sharp`). SHA и фактические размеры — `manifest.json`; происхождение и проверки — `validation.json`.

## Проверки

Все8 нативных браузерных снимков просмотрены: белый/тёмный фон, готовый пол цеха и малый масштаб32/70px на игровую единицу; viewport390×844 и1024×768. Ошибок консоли0, горизонтального переполнения0, все изображения внутри своих панелей. SHA фактически загруженных WebP записаны в `qa/browser-checks.json`; `qa-review.json` привязан к тем же SHA.

На проверенных фонах нет заметной цветной каймы, baked shadow, пола, платы, надписей или обрезанного контура. Отверстия поддона прозрачные. В малом масштабе видимая ширина поддона60.8/133px, бочек70.4/154px; число предметов остаётся читаемым. Крупные белый/тёмный/пол виды служат для проверки края, а не фиксированного мирового масштаба.

`npm test`:17 файлов,88 тестов PASS. `npm run typecheck`:PASS. Игровой рендерер, перекрытия клемм, положение относительно станков, физический iPad/PWA/FPS в этом asset-проходе не проверялись; остаются интегратору. Это карточки фиксированного ракурса, не3D-модели.

Пакет сохраняется собственным локальным коммитом без push. После двух карточек следующую зону самостоятельно не начинаем.
