# Покрасочная линия: бак и камера

Задача m0468: два статичных корпуса в стиле industrial-b. Референсы созданы встроенным image_gen; точные промпты — `prompts.json`, исходные пути и SHA — `references.json`. Оригинальные PNG сохранены в `refs/`.

## Контракт

- `paint-tank`: полный размер около 1.2 × 1.4 × 1.0, пол Y=0. Насос входит в статичный корпус, патрубок направлен в +X. Патрубок измерен: центр торца (0.6,0.509,0.001), наружный радиус≈0.116; канал радиусом0.09 открыт до X=0.45. Подключение шланга — к торцу по направлению +X. Бак ставится по нижней границе Y=0 с `model('paint-tank',{width:1.2})`; штатную игровую высоту основания добавляет интегратор.
- `paint-booth`: полный размер 2.2 × 1.8 × 1.6, пол Y=0. Сквозной проход вдоль X, свободный размер по Z не менее 1.4, по Y не менее 1.0. В модели нет ленты, пола, дверей или декора внутри прохода.
- Для обоих итоговых GLB: один материал, WebP 512², Meshopt, не более 4000 треугольников. Текстуры загружаются через ImageLoader, как в существующем проекте.

## Сборка и проверка

Raw сохраняются локально в `assets-src/raw/factory-evening-2026-10-27/`; существующее исключение Git не обходится. Перед сборкой необходимо визуально проверить оси raw, выставить точные координаты в `tuning.json` и отметить `reviewed:true`. Пока этот флаг false, сборка намеренно запрещена.

```sh
node assets-src/design-pass/kit/factory/machines-3d/evening-paint/inspect.mjs paint-tank paint-booth
node assets-src/design-pass/kit/factory/machines-3d/evening-paint/build.mjs paint-tank
node assets-src/design-pass/kit/factory/machines-3d/evening-paint/validate-geometry.mjs paint-tank
```

`build.mjs` сохраняет только локальные candidate и отчёты. После осмотра кандидат переносится в одноимённый `public/models/`. Скрипт использует зависимости проекта и ранее установленный `/tmp/electro-factory-csg/node_modules/three-bvh-csg`; этот временный пакет нужен только для пересборки, не для загрузки GLB игрой.

`qa.html?m=paint-tank` открывает финальный GLB. Параметры `&raw=1` и `&candidate=1` выбирают исходник или локальную сборку. Восемь ракурсов включают оба торца и низ; проверочный объём показывает проход камеры или просвет патрубка. Нативные кадры должны быть сохранены и осмотрены при 390×844 и 1024×768. Fallback отсутствует.

`validate-geometry.mjs` проверяет размеры и нижнюю границу. У камеры дополнительно проверяются пересечения треугольников с внутренним прямоугольным объёмом, отсутствие приклеенного пола и 49 сквозных лучей вдоль X. У бака проверяется направление +X и отсутствие поверхностей в просвете патрубка. Эти проверки выполняются на итоговом декодированном GLB.

Текущая готовность и блокеры — `progress.md`. paint-tank готов: 95 868 Б, 3907 треугольников; validator0 ошибок/предупреждений, geometry PASS, четыре нативных кадра на390/1024. paint-booth также готов: 119 544 Б, 2948 треугольников; validator0 ошибок/предупреждений, geometry PASS, пять нативных кадров на390/1024.
