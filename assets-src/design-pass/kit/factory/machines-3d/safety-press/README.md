# Пресс: первый заводской GLB

Владелец прямо разрешил включённые кредиты 27.10.2026. Один заказ Tripo Studio H3.1/4000 triangles/2K/delight, 25 кредитов (5600 → 5575), без PBR/Ultra. Исходник: assets-src/raw/factory-2026-10-27/safety-press.glb (локальный raw, SHA в model-report.json). Принятый PNG не менялся.

Готовый public/models/safety-press.glb: 107740 Б, 3739 треугольников, 1 материал, 512 WebP + Meshopt. Размер модели 1.9×2.3×0.8; текущая интеграция width=1.9 и position=(0,.16,-.35). База в Y0, центр X/Z0, перед +Z.

Исходная модель была низкой и с глухой верхней втулкой. build.mjs воспроизводимо перепрофилирует высоту корпуса по указанным landmarks, раздвигает колонны в пределах основания и вырезает настоящее сквозное отверстие R=.13 под кодовый шток R=.1. Текстура сохранена с уменьшением до512; коллизии исправлены геометрией, ход анимации не менялся. Для выреза установлен three-bvh-csg во временной папке: npm install --prefix /tmp/electro-factory-csg --no-audit --no-fund three-bvh-csg. Можно передать FACTORY_CSG_MODULE с абсолютным путём к src/index.js пакета. Затем node build.mjs из корня не использовать: запускать полный путь assets-src/design-pass/kit/factory/machines-3d/safety-press/build.mjs из корня репозитория; validate-geometry.mjs аналогично.

geometry-review.json: 0 пересечений треугольников с полным swept-box головы; 0 пересечений с цилиндрической оболочкой штока; минимальный радиальный запас .02887. Три крайние/средняя фазы также без пересечений. glTF validator 0 errors/warnings; meshopt не проверяется самим validator, но реально декодирован NodeIO и GLTFLoader.

qa.html использует настоящий SafetyPress и loadModels из src, показывает кодовые кнопки, клеммы и ползун. Нативные 390×844 и1024×768: верх/середина/низ просмотрены, шесть PNG в qa/, ошибок/предупреждений браузера0. Обе кнопки и клеммы видимы. Это геометрическая приёмка, не полный игровой тест удержания двух кнопок и не физический iPad/FPS.

Известное свойство прежнего кода: в нижнем положении короткий шток целиком выходит из верхней втулки, между ним и балкой виден зазор. Ход и длина штока здесь не изменены; отдельное замечание интегратору. Сохранён условный зазор головы до наковальни около .175.
