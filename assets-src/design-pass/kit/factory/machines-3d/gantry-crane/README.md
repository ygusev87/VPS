# Портальный кран — статичная рама

Задача m0468; размеры исправлены Claude в m0473: **width 15**, стойки X≈±7, нижняя грань балки Y≈5.8, верх Y=6.5. Финальный `public/models/gantry-crane.glb`: 99 268 Б, 2915 треугольников, один материал, WebP512/Meshopt. SHA `ebb84cbe49f5e2a7b90c4c3c9b434929de412a25a0437a6b037789685f5ce9e9`.

Использование: `model('gantry-crane',{width:15})`, позиция (0,0,0). Габариты 15×6.5×1.2438, нижняя граница после игрового loader Y=0. Стойки около0.6×0.6; расширенные бирюзовые лапы входят в width15. По оси X рама симметрично центрирована. Груз, тележка, трос, крюк, пульт и клеммы остаются кодом.

## Интеграция тележки

Текущая каретка 1.3×0.55×1.2 при центре Y5.7 входит в балку на0.175. Предложено Claude m0476: `this.trolley.position.y = GANTRY.beamY - 0.3` (=5.5). Тогда верх тележки5.775, нижняя поверхность балки минимум5.80027, зазор0.02527. Верх троса5.45 остаётся внутри корпуса каретки. Исходники src Codex не менял.

`validate-geometry.mjs` проверяет итоговый декодированный GLB, повторяет fit/centering. SAT треугольник/прямоугольный объём проверяет **непрерывные** консервативные объёмы всего хода тележки X±5.5, крюка Y0.7..4.6 и троса. Все три объёма свободны с новой высотой. Старая каретка Y5.7 намеренно проверяется отдельно:221 пересекающий треугольник, это не принятый вариант. Груз и соседи полной карты отдельно не покрыты.
