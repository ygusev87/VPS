# Рука робота — подвижный GLB

Задача Claude m0468. `public/models/robot-arm.glb`: 119108 Б, 3922 треугольника, один материал с WebP 512² и Meshopt. SHA-256: `f18d66e7fd898968e5d15749d8a647997086d7fc146c4d11cfff8ce65d4d1842`.

Референс создан встроенным imagegen (`reference.png`, точный `prompt.txt`), затем один заказ Tripo H3.1 за 25 существующих кредитов (5400 → 5375). Исходный цельный mesh разделён локально CSG на жёсткие сегменты с закрытием срезов; сохранён исходный атлас. Пропорции сегментов и центры вращения приведены к контракту. Это подготовленная под кодовую анимацию модель, а не исходный неотредактированный Tripo rig.

## Подключение

Использовать без fit-масштабирования. `model()` всегда центрирует по bbox, что смещает эту асимметричную модель: вернуть позицию внутренней сцены к нулю **до** установки корпуса на плиту.

```ts
const body = model('robot-arm', {});
body.children[0].position.set(0, 0, 0);
body.position.set(0, PLATE_TOP, -0.15); // PLATE_TOP = 0.16
const turret = body.getObjectByName('turret');
const arm = body.getObjectByName('arm');
// Остальные узлы: foot (неподвижный), claw (дочерний arm).
// Общий игровой масштаб детали ×1.5 оставляет вызывающий код.
turret.rotation.y = Math.sin(t * Math.PI * 2) * 1.4;
arm.rotation.z = -0.3 - Math.abs(Math.cos(t * Math.PI * 2)) * 0.4;
```

Группы `foot` и `turret` — дети сцены. `turret` pivot (0,0.25,0), `arm` — ребёнок turret с pivot (0,1,0), `claw` — ребёнок arm с pivot (0.9,0,0). Анимировать **группы**, не `*-geometry`: внутренние mesh-узлы несут преобразования квантования Meshopt. Встроенных анимационных клипов нет. Статичное основание Ø0.9, высота0.25. Плечо направлено +X, захват вниз.

## Проверка

- `model-report.json`: валидатор 0 ошибок/0 предупреждений; 1 информационное сообщение о неподдерживаемой валидатором EXT_meshopt_compression. Реальная распаковка Meshopt проверена NodeIO и браузером.
- `motion-review.json`: 128 фаз существующего цикла. Основание не смещается; минимальный зазор захвата над верхом основания 0.1383 до масштаба ×1.5. Пересечений с консервативным объёмом основной колонны Y0.6..1.02 нет. Верхние0.23 около плечевого pivot — намеренно перекрывающаяся посадка подшипника, она исключена; не заявляется отсутствие всех пересечений соседних деталей внутри шарниров.
- Восемь нативных кадров 390×844/1024×768: крайние положения, промежуточный наклон, задний ракурс. Ещё два `robot-loader-*` проверяют опубликованный локально файл через настоящие `loadModels/model` и ImageLoader игры. В браузере 0 ошибок/предупреждений.
- Полная сцена завода, соседние устройства и физический iPad/PWA пока не проверены: интеграция у Claude.
