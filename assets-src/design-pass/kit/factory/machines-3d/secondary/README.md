# Четыре заводские secondary GLB

Исходники получены из четырёх утверждённых PNG через Tripo Studio. В `orders.json` — ID заказов, настройки, фактические списания и SHA raw. `upload-manifest.json` связывает точные PNG с прямым разрешением владельца на передачу в Studio. Принятые PNG не изменялись. Ни API, ни покупки, ни пополнения не использовались.

Запуск из корня проекта:

```sh
node assets-src/design-pass/kit/factory/machines-3d/secondary/inspect.mjs lever-box rail-cart socket-board shaft-motor
node assets-src/design-pass/kit/factory/machines-3d/secondary/build.mjs lever-box shaft-motor socket-board
node assets-src/design-pass/kit/factory/machines-3d/secondary/validate-geometry.mjs lever-box shaft-motor socket-board
```

`build.mjs` пишет только локальные `candidate/` и отчёты. Перенос в соответствующий `public/models/` выполняется после подготовки, приёмка — через `qa.html?m=имя` (настоящий GLTFLoader, Meshopt и WebP; fallback отсутствует). `&raw=1` показывает оригинал. Нативные кадры лежат в `qa/`, снимки заказа — в `studio/`.

## lever-box — готов к интеграции

- `public/models/lever-box.glb`: 82 708 Б, 3900 треугольников, один материал, 512² WebP, Meshopt. Размер 1.5 × 0.4 × 1.1 с погрешностью квантования меньше 0.00001.
- Только статичный корпус. Отверстие перенесено на XZ (0, −0.35), создан настоящий сквозной канал; из воротника вырезан объём полного хода фактического наклонного рычага. Проверка 45 углов −0.55…+0.55: 0 пересечений поверхности корпуса с цилиндром ручки R0.06/H0.75.
- Установка: `model('lever-box', {width: 1.5})`, позиция (0, 0.16, 0). Существующий pivot рычага (0, 0.51, −0.35) сохраняется. Рычаг и ручка остаются кодом.
- Три знака уже нанесены на крышку. Интегратору нужно согласовать существующие runtime markers: в коде STOP пока круг, в принятом референсе/GLB квадрат; не накладывать второй непрозрачный набор знаков.
- В GLTFLoader осмотрены 1024×768 и оба крайних положения на 390×844. WebP видим, модель целиком в кадре; ошибок браузера и переполнения нет. Это локальная проверка корпуса и реальной геометрии рычага, не утверждение о проверке физического iPad или полного игрового сценария после интеграции.
