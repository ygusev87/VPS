# Бордюр города

`kerb-strip.webp`: 256×2048,46 436байт, native alpha; лента0,5×4 игровых единицы. Светлый камень и короткая мягкая тень справа. Первый built-in imagegen дал торец сверху и обрезанный камень снизу; одна целевая правка сделала оба края срезами середины камня. Всего2 вызова. Оба PNG и полные промпты сохранены, исходный и выходной SHA — в manifest.json.

Исходник887×1774. Техническая обрезка прозрачного горизонтального поля x350…573 (224×1774), затем Lanczos resize256×2048/sRGB/WebP85/alpha100. Удалённый фон имеет максимумalpha1 и0,000223% общего веса альфы. Камни и тень сохранены без порогов, перекраски и рисования кодом. Внутри crop нативная альфа сохранена.

В QA просмотрены белый/чёрный/зелёный фон, вертикальные повторы, ширины16/32/64px и прямоугольный газон18×12ед на paving C. Бордюр читается тонкой светлой окантовкой. Браузер390×844 и1024×768:4/4 текстуры загружены,0 ошибок и переполнения,8 нативных JPEG в qa/. Контуры без видимых белых/жёлтых ореолов. Противоположные строки отличаются в среднем3,94RGB, поэтому попиксельная бесшовность не заявляется. Повтор визуально непрерывен; рисунок камней на стыке чуть меняется. Схематичные углы preview не воспроизводят miter/overlap runtime ribbons: их ревью у Claude.

Пакет принят для интеграционного ревью, `kit.json` включает kerb-strip. Код игры, iPad/Safari/FPS/PWA здесь не проверялись. Общая QA также проверяет контрастную плитку из ../paving-contrast/. На сравнительном листе оба верхних образца используют64px на8ед, оба нижних128px; подписи по горизонтали не означают разные масштабы A/C.
