## Альфа и основание

Применены только технические операции: прямоугольная обрезка прозрачного поля по bbox alpha>16 с запасом8 исходных пикселей, пропорциональное уменьшение Lanczos и укладка на прозрачный квадрат. Значения альфы внутри сохранённого прямоугольника не пороговались и не перекрашивались. По всему набору за обрезкой остался только слабый фон alpha1–2, максимум0,018656% суммарного веса альфы у bush A; пиксели alpha>16 не удалены. Полные исходники остаются доступными. Край исходника имеет максимумalpha3, поэтому видимая листва не обрезана рамкой.

У деревьев X якоря измерен по альфа-взвешенному центру нижних2% видимого основания ствола, Y — сразу под последним рядом alpha>128. У кустов и цветников X — середина видимого силуэта, Y — его основание. Это якорь размещения, не восстановленный скрытый корень. Пиксельные и нормализованные координаты находятся в `manifest.json`; отдельная игровая тень не запечена в карточки.

## Проверка

На всех семи ассетах визуально проверены белый, чёрный и принятый городской `lawn-main-a`, крупный вид и мелкие размеры: деревья64/96/128px, кусты48/64/96px, цветники32/48/64px. Заметных ореолов, грунтовой подложки и нарисованной тени нет. Силуэты и цветовые варианты различимы при уменьшении.

Браузер действительно отрисовал каждую карточку при **1024×768 и390×844**: 14/14 загрузок, правильные размеры изображений, отсутствие горизонтального переполнения,0 ошибок консоли. Сохранены14 полных страниц и2 общих листа нативными JPEG. Визуально просмотрены все семь планшетных страниц, оба общих листа и полные телефонные страницы tree A / flowerbed B; одинаковая телефонная раскладка остальных дополнительно проверена по DOM. `qa-review.json` фиксирует выводы, `qa/browser-checks.json` — фактические размеры окна и загруженные URL с SHA.

`npm test`:17 файлов /88 тестов успешно. `npm run typecheck`:успешно. Экспортные SHA, альфа, размеры и точки основания проверены повторной сборкой.
