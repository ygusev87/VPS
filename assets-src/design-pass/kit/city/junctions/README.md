# Город: угол, перекрёстки, тупик, переход

26.10.2026. Пять WebP для CITY-KIT, всего **676588 байт**. `road-corner`, `road-tee`, `road-cross`, `road-end` — 1024², 7×7 игровых единиц; `zebra` — 1024×512, 6×3 единицы. Базовые направления: угол S/E, tee W/E/S, cross N/E/S/W, end S. Переход располагается поверх асфальта, без бордюров.

Всего 11 встроенных вызовов. Первые corner/tee сузили въезды; end оставил широкие пустые поля; zebra требовал проверки/очистки полупрозрачных следов между полосами. После целевых исправлений отдельный проход осветлил асфальт corner/end. Все исходники и ранние версии сохранены в ../sources, точные промпты и пути — prompts.json. Чистый вид альфы проверен по браузерному композиту, а не чёрному фону выдачи генератора: у него слабые фоновые пиксели выглядели непропорционально яркими.

`node assets-src/design-pass/kit/city/junctions/build.mjs` выполняет только упаковку: у corner/end прямоугольное удаление внешних полей по границе alpha>=16, сохранение всех значений альфы внутри, sRGB, Lanczos resize-fill и WebP quality85/alpha100. Отсечённый alpha-вес: corner 0.00886%, end 0.00235%. Это технический crop, не маска/перерисовка; полные оригиналы сохранены. У остальных только resize/encoding. Исходники 1254² и 1774×887 у zebra. Manifest содержит размеры, crop, SHA-256, альфу и края.

## Визуальная проверка

Native browser, локальный `preview.mjs` (по умолчанию порт65495). `viewport.html` содержит iframe1024×768/390×844. Внутренняя ширина/scrollWidth:1024/1024 и390/390, горизонтального переполнения нет. Проверены все пять плиток рядом с настоящей road-strip-a, белый/чёрный/зелёный фон, угол во всех четырёх поворотах, мобильный tee180° и zebra. Девять финальных JPEG в qa/. Нативные окна1265×712 и1280×720 обрезают нижнюю часть внешнего iframe: это не полный screenshot768/844px и не физическая проверка iPad.

Стыки пригодны для интеграционного ревью, но не попиксельно бесшовны: длины камней и фаза штрихов различаются, у corner заметна тонкая линия на границе, местами бордюр выступает на несколько пикселей. При runtime надо проверить существующий overlap ROAD*0.58 против half-tile3.5, alphaTest/фильтрацию и вид с игровой камеры. В qa.html показан строгий стык без скрывающего перекрытия. Глобальное затемнение у corner/end устранено, небольшие вариации тона/зерна остаются. Не заявляется физически точная равномерная ширина бордюра во всех пикселях.

`zebra` проверена при масштабе6×3 поверх полосы общей ширины7. На исходном разрешении остаются единичные почти прозрачные пиксели между краями, на трёх фонах и игровом размере видимого грязного ореола нет. Нативная альфа сохранена, вручную не порогована.

Имена включены в city/kit.json для передачи интегратору. Включение нового города всё ещё зависит от принятой paving-main в runtime. Проверка игры/камер/общих взаимодействий — следующий шаг Claude. Перед коммитом: npm test и npm run typecheck; итог записан в progress.md.
