measure.mjs считывает фактический WebP, выделяет связное мощение только для измерений, проверяет границу и семь зон уже в runtime-размере. Маска не сохраняется в ассет, пиксели не редактируются. Цветовая сегментация/эллипс — приближение, не доказательство корректности полной 3D-сцены. Скрипт воспроизводится из корня проекта и пишет только measurements.json.

**Fallback:** процедурный basin() использует TorusGeometry(3.2,0.35), то есть внешний радиус 3,55. Он не помещается на площадке даже после совмещения. Для него Claude должен оставить прежний газон или привести внешний размер к тому же 6,4, что у загруженной модели. Принимать fallback как проверенный нельзя. Не уменьшать игровую зону воды без проверки механики.

Просмотрены четыре исходных браузерных JPEG при фактических viewport 390×844 и 1024×768: общая карта и увеличение. Красная граница запаса полностью внутри мощения после сдвига; розовые зоны устройств свободны. В каждом размере loaded4, errors[], scrollWidth=innerWidth. Разметка существует только в SVG страницы QA. Это проверка размещения ассета, не игровой WebGL/iPad/FPS.
