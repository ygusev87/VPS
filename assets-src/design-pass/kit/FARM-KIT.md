# Ферма: набор готовых картинок (asset-first)

26.10.2026, решение владельца: всё неподвижное — готовые нарисованные ассеты, которые ставятся как есть.
Шейдер больше не «рисует» землю: он только кладёт картинки. Ориентир вида — `../variants/farm-a.png`.

## Общие правила для всех картинок
- Стиль как в farm-a: тёплая, сочная, мягко-живописная мобильная ферма (Hay Day), без чёрных контуров.
- Свет **снизу слева** (юго-запад; солнце в игре в точке (−7, 12, 5) от цели, камера смотрит с юга под 52°).
  Мягкие тени уходят вверх вправо. Одинаково на всех картинках.
- Верх картинки = север (−z в игре), право = восток (+x).
- Земля и декали — строго сверху (ортогонально), без перспективы, без теней от больших предметов.
- «Карточки» (колосья, деревья, кусты) — вид 3/4 сверху, как с камеры игры (52° над горизонтом), прозрачный фон,
  низ предмета на нижнем крае без тени (тень кладём отдельно).
- WebP (sRGB), качество ~85; с альфой там, где сказано. Без надписей и рамок.
- Делать сразу 2–3 варианта каждой картинки (генерация почти безлимитна); я выберу в игре сравнением с farm-a.
- Исходники — `assets-src/design-pass/kit/farm/sources/`, готовые — `public/textures/kit/farm/<имя>.webp`.
