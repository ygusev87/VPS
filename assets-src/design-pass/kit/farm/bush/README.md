# Кусты лесной кромки

Два готовых WebP 512×512, всего **80364 байта**. Более широкие плотные формы с мелкими округлыми листьями, согласованные с дубами, отличаются от небольших `shrub-card-a/b` лугов.

| Имя | Байты | Нижний центр X,Y от верхнего левого | Three Sprite.center X,Y |
| --- | ---: | --- | --- |
| bush-card-a | 39048 | 256.5,508 | 0.500977,0.007813 |
| bush-card-b | 41316 | 256,508 | 0.5,0.007813 |

Каждый ассет получен отдельным built-in imagegen-вызовом; всего2, повторов0. Полные исходные PNG побайтово скопированы в `../sources/`; пути генератора, размеры и SHA в `generation-log.json`. Точные аргументы и SHA визуально просмотренных farm-a/tree-oak-card-a/b/grass-main-a сохранены в `prompts.json`. Для новых генераций изображения не передавались: их стиль описан текстом по просмотренным ориентирам.

`build.mjs` выполняет только техническую подготовку: прямоугольный crop по alpha>16 с запасом8 исходных пикселей, пропорциональный Lanczos-resize, прозрачную упаковку, sRGB WebP quality85/alphaQuality100. Значения альфы внутри crop не заменяются и не порогуются. Фактический аудит: удалены лишь дальние фоновые пиксели с alpha1–2, до0.0154% суммарного alpha-веса; ни одного пикселя alpha>2 не удалено. Полные оригиналы сохранены. Цветокоррекции, масок, procedural art, дорисовки или исправления вручную не было.

Опорная точка — горизонтальный центр видимого силуэта alpha>128 и строка сразу под его нижним краем. Это anchor для размещения; корень скрыт листвой и не измерен. У обоих кустов видимое основание на4px выше нижнего края. Исходники целиком помещаются в рамке; её край содержит только alpha0–2. Нижний центр и cropAudit подробно записаны в manifest.

## Проверка

`qa/bush-card-a.jpg` и `qa/bush-card-b.jpg` — прямые снимки внутреннего браузера: белый, чёрный и фактический grass-main-a; крупный вид и64/96/128px. Оба снимка успели сохраниться до ручного прерывания и были просмотрены после подтверждённого ответа владельца «Продолжать оба чата». Нет белой/чёрной подложки, горшка, земли и отдельной запечённой тени; широкие формы читаются во всех трёх размерах. Кандидаты готовы для игрового ревью. Точный угол52° задан художественным ориентиром, но по растру не измерен. Проверка не подтверждает игровой масштаб, перекрытия, iPad/PWA/FPS.

Повторная сборка из корня: `node assets-src/design-pass/kit/farm/bush/build.mjs`. Скрипт проверяет SHA оригиналов и сохраняет визуальный статус только при совпадении SHA с `qa-review.json`. Для просмотра: `python3 -m http.server 33342 --bind 127.0.0.1`, затем `/assets-src/design-pass/kit/farm/bush/qa.html?asset=bush-card-a`.

`kit.json` и runtime не изменялись. Основной чат добавляет имена и передаёт интегратору. Flora готова в ab71950; field —15f11f2, уже принят в игре по сообщению main.
