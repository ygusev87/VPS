# Свинарник: земляной пол и короткий подход

Вместо светлого пола у входа модель использует землю с редкой соломой. `public/models/pigsty.glb` готов:187896байт,2891треугольник,2OPAQUE-материала,2WebP-текстуры512²,Meshopt. Одна дополнительная отрисовка и текстура относительно прежней модели. Исходный atlas корпуса сохранён точно.

`build-floor.mjs` выделяет74целых треугольника пола (включая3грани правого склона) без срезов и перемещения вершин. `audit-floor.mjs` независимо проверяет равенство декодированных POSITION/NORMAL, матриц узлов, UV корпуса и ориентированных треугольников с учётом циклического порядка индексов. glTF-валидатор:0ошибок/0предупреждений; Meshopt отдельно декодирован аудитом. Полная замкнутость исходной модели не утверждается.

`floor-source.png` — одна встроенная генерация; точный запрос в `floor-prompt.json`. Единственная обработка: полный resize512×512 и WebP quality85. Ни новых Tripo-заказов, ни платного API. `originals/` сохраняет исходный GLB, `candidate/` — точную копию поставки. Путь к репозиторию в скриптах определяется относительно самих файлов.

## Подход — для интеграции Claude

В `placement.json` точный контракт. Положение/fit свинарника остаются прежними:width10,rotateY−π/2,world(27,0,−26.5). От порога через северный проём забора идёт только короткий отрезок к существующему грязевому двору:

```ts
toned(ribbons(
  [{pts:[[27,-22.7],[27,-19.5]],w:1}],
  kitPieces('farm','path-strip',true)[0],
  3.6,8.8,.006,-1,.3
),'#c8d4f0')
```

Добавить отдельной группой при готовом path-strip. Полная ширина холста x25.2..28.8 помещается в проём24.456..29.584 с запасом. Южный конец скрывается под существующей грязью благодаря renderOrder−1. Не переносить двор, забор, корытце, свиней и задания. Main не менял runtime/PATHS.
