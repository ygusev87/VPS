Кандидат worker **2ca8d29** технически принят для дальнейшего решения по бюджету: четыре отдельные замкнутые колёсные поверхности, локальная ось X, сохранённый внешний протектор. **13 416 треугольников / 249 536 Б**, цель 8 000 не достигнута. `public/models/tractor.glb` не заменён. Это не приёмка игрового движения или производительности iPad.

`audit.mjs` независимо читает конечный GLB через NodeIO/Meshopt. Подтверждены 11 382 исходных треугольника вне маски из 2 174 изменённых граней, с сохранением всех исходных атрибутов и ориентации. Допускается лишь циклический сдвиг индексов грани. Материал, три изображения, корневой TRS и габариты совпадают. Четыре колеса имеют по одному связному компоненту, ноль открытых/неманифолдных/неправильно ориентированных рёбер и ноль дефектов циклических связей при вершинах. У корпуса остаются шесть исходных неманифолдных рёбер; глобальную манифолдность не заявляем.

Непрерывное вращение проверено консервативным разделением реальных треугольников на полосы X шириной ≤0,00075. Задние радиальные запасы в общих полосах после fit: 0,029018 и 0,025988. Это **не глобальные минимальные евклидовы расстояния**. Особенно передние значения 1,2455/1,2470 нельзя выдавать за зазор у осей: близкие части оси находятся в соседних диапазонах X. Пары колёс разнесены по X или непересекающимся окружностям YZ при любых независимых фазах.

Посадка не идеально круглая. При фазе 0 передние низшие точки находятся на 0,019541/0,024876 над землёй; их минимумы за полный оборот — 0,015545/0,019664. Задние шины могут уйти ниже Y=0 до −0,002624/−0,004658. Эти значения измерены при исходном fit `depth:3.8, rotateY:Math.PI`, без подвески и правки центров. Внутренние стенки — заметно плоские тёмные кольца. Умолчать об этих компромиссах при интеграции нельзя.
