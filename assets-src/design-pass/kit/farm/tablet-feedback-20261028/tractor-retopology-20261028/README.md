# Трактор: экспериментальное разделение колёс

Готов локальный кандидат с четырьмя замкнутыми колёсами, вращающимися вокруг собственной локальной оси +X. Исходный трактор в `public/models/tractor.glb` не заменён. Статус: **READY_EXPERIMENTAL_ABOVE_TARGET**.

| Параметр | Исходник | Кандидат |
|---|---:|---:|
| Треугольники | 13 556 | 13 416 |
| Размер GLB | 240 008 Б | 249 536 Б |
| Материалы | 1 | 1, исходный |
| Отдельные узлы колёс | 0 | 4 |

Цель 8 000 треугольников не достигнута. Один сохранённый корпус занимает 6 564 треугольника; оставшихся до цели 1 436 недостаточно для нынешних четырёх колёс с сохранением протектора. Это кандидат для ревью геометрии и вращения, а не оптимизированная модель для публикации. Рост файла на 9 528 Б связан с разделёнными мешами, атрибутами закрывающих поверхностей и иерархией.

## Что изменено

- Внутренние стенки шин срезаны по оси X и закрыты плоскими кольцевыми поверхностями с учётом отверстий ступиц. Внешний протектор сохранён; внутри колёса стали уже. На новых поверхностях используются образцы из исходного атласа.
- У корпуса заменены только 22 исходных треугольника в области задних креплений. 6 416 исходных треугольников корпуса имеют побитово прежние POSITION, NORMAL и TEXCOORD_0. Неплоские отверстия креплений закрыты 148 треугольниками.
- В центре передней левой ступицы устранены исходные дефекты: удалены 30 треугольников, включая двусторонний дублированный выступ, и добавлены 12 треугольников закрытия. Проверка ограничивает эту правку радиусом 0,09 вокруг центра ступицы.
- Сохранены исходный корневой TRS, квантизация, материал и все три текстурных изображения. Габариты до/после совпадают с точностью меньше 1e-12. Формы корпуса вне маски не менялись.

`change-mask.json` содержит номера исходных изменённых граней и новых граней по частям. `original-mask/tractor.glb` отмечает изменённые исходные грани малиновым. `mask/tractor.glb`: серый — сохранено, малиновый — срез, оранжевый — реконструкция. Числа граней маски относятся к порядку треугольников соответствующего меша.

## Поворот и посадка

Иерархия: исходный `tripo_node_*` → `tractor-body` и четыре `wheel-*` → соответствующие `tire-*`. Вращать `wheel-*` вокруг локальной X; дочерний `tire-*` компенсирует смещение pivot. Корневую квантизующую трансформацию и компенсацию дочерних узлов не обнулять.

Координаты ниже даны в системе исходной сцены glTF до игрового fit. Радиус — максимальное расстояние вершины от оси в плоскости YZ, включая протектор. Pivot Y/Z — центр габаритов колеса; X — середина его нового осевого диапазона. Полные значения и pivot в локальных координатах родителя записаны в `manifest.json` и `build-report.json`.

| Узел | Центр X / Y / Z | Радиус | Треугольники | Минимальный зазор до корпуса при полном обороте |
|---|---|---:|---:|---:|
| wheel-front-right | 0.253050 / −0.247856 / 0.368694 | 0.128115 | 826 | 0.327732 |
| wheel-front-left | −0.253336 / −0.246941 / 0.368847 | 0.127947 | 798 | 0.328152 |
| wheel-rear-right | 0.255233 / −0.136898 / −0.262757 | 0.243854 | 2 618 | 0.007634 |
| wheel-rear-left | −0.255090 / −0.136746 / −0.262482 | 0.244542 | 2 610 | 0.006824 |

Просмотр повторяет игровую посадку: поворот сцены на π вокруг Y, глубина 3,8, центрирование по XZ, нижняя точка Y=0. При таком масштабе минимальные задние зазоры равны примерно 0,0290 и 0,0259. Локальная ось +X после игрового поворота направлена в −X сцены; это ожидаемое преобразование.

## Проверки и ограничения

- `audit-report.json`: независимое декодирование итогового GLB; совпадение реконструкции с проверенной сеткой, побитовая сохранность исходных атрибутов, текстурные хеши, габариты, pivot, неподвижность корпуса и неизменность публичного трактора.
- У каждого колеса: 0 открытых рёбер, 0 неманифолдных рёбер, 0 пар рёбер с одинаковым направлением, 0 вырожденных граней. У корпуса нет открытых рёбер; **сохранились 6 исходных неманифолдных рёбер** вне правки. Весь трактор не объявляется полностью манифолдным.
- `surface-check.json`: все 905 новых треугольников проверены на пересечения с поверхностями собственной части; пересечений нет. Исходные пары сохранённых граней повторно не исправлялись.
- `sweep-report.json`: непрерывный оборот, а не только несколько кадров. Декодированные треугольники корпуса и колеса обрезаются полосами X шириной ≤0,001. Максимальный радиус колеса и минимальный радиус корпуса в каждой полосе дают консервативный положительный зазор для всех углов 0…360°.
- `validator.json`: 0 ошибок. Пять предупреждений об отсутствии сохранённых tangent-атрибутов — по одному на меш; тот же тип предупреждения присутствует в исходнике. Meshopt дополнительно проверен после декодирования, поскольку валидатор не разбирает его payload напрямую.
- Нативный встроенный браузер: 1024×768 и 390×844; фазы 0/45/90°, два противоположных ракурса, нижний ракурс, обе маски. Во всех 10 проверках кандидата 4 колеса, 6 212 вершин корпуса, максимальное движение корпуса **0**, горизонтального переполнения нет. Консоль без ошибок/предупреждений. Кадры и измерения — `qa/`.
- `npm test`: 17 файлов / 88 тестов, PASS. `npm run typecheck`: PASS. Физический iPad и подключение кандидата к игровой сцене не проверялись; текущая задача ограничена отдельным кандидатом.

Внутренние стенки визуально плоские и темнее исходных округлых стенок; это явный компромисс реконструкции, видимый снизу. Для принятия в игру остаются ревью вида внутренних стенок, бюджет геометрии и проверка на реальном iPad.

## Воспроизведение

Все исходные данные находятся в этой папке, включая снимок семантической разметки предыдущего исследования. Внешняя генерация и API не используются. Из корня репозитория:

```sh
cd assets-src/design-pass/kit/farm/tablet-feedback-20261028/tractor-retopology-20261028
node build.mjs
node masks.mjs
node check-surfaces.mjs
node sweep.mjs
node audit.mjs
```

`mesh-debug.json` создаётся сборкой и исключён из Git; он нужен проверкам поверхностей и маскам. Повторная сборка дала тот же SHA-256 кандидата. Для интерактивного просмотра запустить Vite из корня репозитория и открыть путь этой папки с `/qa.html`; `review.html` содержит сохранённые сравнительные кадры и не требует WebGL.
