## Оригиналы и прозрачность

`prompts.json` хранит точные tool arguments каждого вызова, размеры экспорта и SHA трёх визуально просмотренных ориентиров: farm-a, grass-main-a, path-strip-a. В новые генерации файлы не передавались: стиль описан текстом по этим ориентирам, в соответствии с правилом инструмента для новых изображений. `generation-log.json` содержит фактические generated_images пути, байты/SHA и копии PNG в `../sources/`. Полные оригиналы сохранены без изменений.

Техническая обработка — прямоугольная обрезка лишней рамки, пропорциональное уменьшение Lanczos, прозрачная упаковка, sRGB WebP quality85/alphaQuality100. Рамка определяется границами alpha>16 с запасом 8 исходных пикселей со всех сторон. **Значения альфы внутри прямоугольника не порогуются и не заменяются.** Аудит фактических девяти изображений: за прямоугольником оказались только пиксели alpha1, около 0.0016% максимум суммарного alpha-веса; ни одного пикселя alpha>1 не удалено. Они были редкими следами генерации далеко от растения. Это устранило пустые нижние поля в7–17% изображения. Точные числа в `transform.cropAudit`; исходные PNG полностью сохранены.

Не использовались chroma key, нарисованные маски, цветокоррекция, процедурная графика, дорисовка или повторная генерация. Изображения без подложки/горшка/запечённой падающей тени. Свет читается слева, листва в тёплой оливково-жёлтой гамме. Вид52° задан в промптах; точный угол по растровой картинке не измерен и должен быть принят по сравнению в игре.

## Повторение и проверка

Из корня проекта: `node assets-src/design-pass/kit/farm/flora/build.mjs`. Пишет только свои9 WebP и manifest, проверяет SHA оригиналов, размер и наличие альфы. При повторной сборке визуальный статус переносится только при совпадении SHA с `qa-review.json`.

`python3 -m http.server 33342 --bind 127.0.0.1`, затем `/assets-src/design-pass/kit/farm/flora/qa.html?asset=tuft-card-a`. Страница читает manifest без кэша и загружает каждую картинку с SHA в URL; сверху ссылки на9 вариантов. `qa/` — финальные прямые JPEG-снимки браузера после технической обрезки. Мелкие previews проверяют читаемость рисунка, не производительность устройства. На 32 px мелкие лепестки закономерно сливаются; сохраняется цветочная группа. Травяные цветки B/C на 32 px менее заметны, чем отдельные flower-card.

Все9 имён готовы для интеграционного ревью и добавления основным чатом в kit.json. Размещение, игровой масштаб, перекрытия и сравнение с farm-a проверяет интегратор. Текстуры поля находятся в соседнем field/ (коммит15f11f2); ruts-strip там имеет отдельно задокументированное ограничение стыка.
