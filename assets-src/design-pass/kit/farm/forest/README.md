## Подготовка

`node assets-src/design-pass/kit/farm/forest/build.mjs` — sRGB, WebP85, alpha100. У дерева убираются только пустые строки ниже последнего пикселя alpha>=16, затем contain/south в1024². Крона и пропорции сохраняются; рисунок, цвета и исходная альфа не перерисовывались. У остальных resize-fill; дорожка из887×1774 растягивается в512×2048, поэтому её детали вытянуты вдоль движения. Исходники сохранены для другого решения при интеграции.

Нижний контакт всех деревьев при alpha>=16 на последней строке. При alphaTest0.45 просвет0px у oak-a/b,pine-a и1px у oak-c,pine-b. В размере128px это меньше0.13px. Кроны целиком помещаются в изображении. Визуальный ракурс соответствует стилизованной карточке; точные52° из растра не подтверждены.

У тени максимальная альфа140/255 (55%), все четыре края полностью прозрачны. Если в игре темновато — уменьшить opacity; это отдельная тень, в деревьях её нет. Это ограничение фактического результата относительно более лёгкой тени в промпте.
