## Воспроизведение

`python3 assets-src/design-pass/farm-interior/integrate.py` создаёт изолированный кандидат из актуальных общих данных и двух handoff-файлов. Он отказывается работать, если исходные растительные группы уже изменены, не трогает общие файлы и сохраняет все байты вне трёх массивов items. `--apply` переносит только явно проверенный кандидат, предварительно сверяя хеши общих файлов, кандидата и handoff.

`prepare.py` создаёт временный снимок актуального коммита, подставляет кандидат и подключает QA-интерфейс исполнителя. Его сервер: `node node_modules/vite/bin/vite.js --config qa-vite.config.mjs`, страница `/qa.html`. `verify.py` проверяет сохранённые JSON-отчёты. `qa/camera-snapshot.json` фиксирует источник камерного аудита; `snapshot.json` — более поздний кадр с золотым полем.

Интеграция 4b36d0b и подготовка исполнителя 5ce852f отправлены в origin/dev. Claude выполняет игровой робот, синхронизацию общего validator26, проверку взаимодействий и разрешённую владельцем публикацию. Временная вкладка и сервер основного Codex закрыты.
