# Повторное ревью: 7454b85 → 09304c6

**Результат: замечания по новым деталям закрыты в настольном QA на09304c6.** Кегли с красными шейками/верхушками заметнее, ночной ореол гирлянды уменьшен; у подставки остаётся локальный розовый отсвет, но большая жёлтая засветка всей детали из исходного ревью убрана. Повторный прогон не является проверкой физического iPad/PWA/FPS.

## Найденная при проверке регрессия

В7454b85 уменьшили общий `glowLight().power`, которым пользуются и визуальный PointLight, и игровая реакция фотодатчиков. Датчик перед гирляндой на+1.55поZ, без наложения плат, имеет дистанцию1.7111 от световой точки до глаза. В actual main.ts при3В lux0.16977, при6В0.22406; оба меньше порога включения0.28, closed=false. Для тех же measured shown прежняя формула shown×0.7 даёт0.39612/0.52281. Старое поведение здесь рассчитано той же функцией ослабления, а не выдаётся за запуск старого коммита.

Сохранены `toys-fix-sensor-3v.json`/`toys-fix-sensor-6v.json`. Сообщение Claude m0242. Он исправил в09304c6: отдельный `sense` для фотодатчика, мягкий `power` только для отрисовки. Остальные источники сохраняют прежнее поведение через `sense ?? power`.
