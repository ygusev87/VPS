# Город: визуальная подготовка

Статус: концепты одобрены Claude в m0103. Первый пакет — пекарня, пекарь, asphalt/paving — готов к интеграции. Задача city-assets остаётся в работе. Каждый объект получает отдельный Image-референс перед конвертацией в 3D.

## Концепты

- buildings-style-v1.png: дом бабушки, пекарня, школа; пожарная часть, магазин игрушек, клуб.
- characters-style-v1.png: бабушка, пекарь, первый ребёнок; второй ребёнок, енот, голубь.
- concepts.html: просмотр с легендой. Референс палитры — существующая public/maps/city.webp; точные промпты в prompts.json.

Формы крупные, скруглённые, цветовые массы спокойные, без мелкого шумного декора. Никаких текстовых вывесок, нужных для понимания задания. Домики распознаются силуэтом, цветом, витриной/воротами и простыми объёмными символами.

На первом листе дом бабушки имеет два полноценных этажа и мансарду, а балкон показан на втором уровне. Это НЕ утверждённая геометрия задания. В отдельном референсе нужно три явных этажа, свободная шахта/место под лифт и площадка строго на согласованной высоте. Claude подтвердил размеры в m0101: плата лифта 2.3×2.3; кабина 0.86×0.72×0.8; пол внизу ≈0.34, наверху ≈1.95; верх башни ≈2.9. Дом шириной около 5, высотой 3–4 стоит слева (−x), фасадом к +z. Балкон на правом (+x) торце: пол y=1.95, ближайший край x=−0.65 от центра лифта, глубина вдоль z около 1.2 с центром z=−0.25. Бабушка входит с +z, выходит на −x. Метод cabinFloor() возвращает точное мировое положение пола. Геометрию дома привязывать к этим размерам, а не к картинке; сохранить отдельный ориентир площадки для интеграции.

## Повторное использование

| Объект | Решение |
|---|---|
| Кошка | kitten.glb, без новой генерации |
| Деревья, кусты, цветы, камни | Уже готовые модели фермы, инстансы |
| Пожарная машина, светофор, электрические детали | Существующие игровые модели |
| Вторая легковая машина | Вариант одного нового кузова; палитра/атлас, без второй формы |
| Второй ребёнок | Общая базовая сетка и скелет, цвет одежды через атлас; отдельная модель только если вариант визуально недостаточен |
| 2–3 жилых домика | Один новый дом с вариантами цвета; не генерировать каждый заново |
| Разметка, рельсы, вода, свет, дым | Управляемые игрой эффекты/геометрия, не запекать в модели |
| Трава | Готовые материалы фермы |

## Новые формы

Около 20 статичных форм после переиспользования: восемь зданий (шесть на листе, подстанция, один жилой дом), бабушка, пекарь, один базовый ребёнок, енот, голубь, трамвай, легковая машина, чаша фонтана, скамейка, фонарь, остановка, мусорные баки. Улица должна оставаться просторной: декор только после размещения заданий, с явной зоной исключения вокруг кругов, персонажей и источников.

Трамвай — отдельный вагон без рельсов и проводов. Токоприёмник/колёса, если анимируются, должны быть отдельными частями. Фонарь — без запечённого свечения. Фонтан — сухая чаша, вода от кода. Пекарня — пустая витрина, булки отдельным объектом для появления по успеху. Фасады и балкон не должны перекрывать рабочий круг/кабину.

## Движение персонажей

Енот: скелет и ходьба, как у исправленной лисы; развести лапы и хвост в исходном референсе. Дети, которые бегут в школу, должны переступать ногами. Планировать один общий humanoid-клип для цветовых вариантов. Бабушка при перемещении пешком также требует короткого шага; для статичного пекаря достаточно жеста/небольшой реакции. Не заменять ходьбу скольжением цельной фигуры.

## Предварительный бюджет

Перед городом остаток API был 365 кредитов; после первого пакета — 305, frozen=0. По предыдущим заказам статичный GLB стоил 30, риг и walk лисы — 35 вместе. Это расчёт по фактической истории, не гарантия текущего тарифа.

Консервативный план: не более семи первоочередных API-моделей (210), резерв до 105 на три цикла риг/ходьба, 30 на одну переделку; остаётся 20. Первые семь: дом бабушки после размеров, пекарня, пекарь, бабушка, трамвай, машина, енот. Остальные — через авторизованную Studio-сессию в пределах уже купленного пакета либо перенос части API-заказов в Studio. Перед каждым пакетом проверить реальную цену и баланс; не покупать дополнительные кредиты. Риги людей и их цены уточнить до запуска.

Качество и анимации важнее исчерпания API до нуля. Первый пакет стоил 60 API-кредитов (две успешные генерации по 30). Studio пока не использована: в UI наблюдалось 6200 кредитов, стандартная выбранная конфигурация стоила 55 за генерацию с Ultra/4K/PBR. Это отдельный баланс; настройки и заказ не менялись.

## Бюджет ассетов и следующие шаги

Постройки 8–10 тыс. треугольников, люди/животные 6–8 тыс., мелкий декор 0.8–3 тыс. По умолчанию одна color-карта 512 и матовый материал; normal/ORM добавлять только при заметной пользе. Повторы инстансить, оригиналы хранить отдельно, geometry/rig не уплощать при оптимизации.

Проверка концептов: оба листа осмотрены; HTML проверен при ширинах 1180 и 390, 17 тестов и typecheck проходят.

Следующий шаг: разрешить согласование высоты бабушки и кабины, затем дом/бабушка и оставшийся транспорт. Имя ребёнка — child.glb (m0105); kid.glb принадлежит козлёнку фермы и не меняется. Жилые здания и люди из листа не конвертировать одной общей моделью.
